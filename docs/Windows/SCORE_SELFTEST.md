# 曲谱输出全库自测方案（程序版简谱 ↔ 印刷 PDF）

> 目标：**把 473 首诗歌的「曲谱+歌词」按 App 的输出方式逐行渲染出来，与印刷 PDF 一一比对，
> 定位差异点 → 归类统计 bug → 统一修复 → 回归到零差异（或白名单）**。
> 建立日期：2026-09-21（第四轮反馈）。工具：`tools/score_selftest.py`。

## 二、分层比对（成本从低到高，逐层收敛）

### L0 数据级：`code_seq` 码位 ↔ PDF 字形码位（全库，分钟级）
- **做法**：逐首打开 `*_简谱.pdf` → `page.get_texttrace()` 取 MMP2005 字形的原始码位 →
  过滤文本层的填充符（`0020` 空格、`3021` 分隔竖线）→ 与库内 `code_seq` 的 token 展开序列**逐元素比对**
  （按 `y ≈ db_y + Δ` 配行，Δ 在 ±10pt 内搜索最优）。
- **判据**：序列完全相等 = `equal`；首个不等位置 = `diff@i`；找不到对应行 = `row_missing`；多余行 = `row_extra`。
- **通过标准**：`equal` 行占比 = **100%**（一轮已抽样 3 首全等）。**这一层不允许有偏差**——它是渲染的地基。
- **产出**：`report_l0.json` + `summary`（每首的 equal/diff/missing 计数 + 差异样例）。

### L1 渲染自检：不依赖 Flutter 的程序化重绘（分钟级）
- **做法**：用**同一份字体**（`assets/fonts/jianpu_mmp2005.ttf`）+ **同一份度量**
  （`lib/data/jianpu_metrics.dart`）+ **同一套版式常量**（槽距 1.0、歌词 0.5、小节线裁剪…）
  在 Python(PIL) 侧重绘每行（音符行 + 歌词行），产出 `rows/<hymn>_<line>.png`。
- **判据**：① 每个 token 的码位都能在字体 cmap 与度量表中找到（缺字 = 渲染空缺）；② 渲染出的
  **墨迹簇数 = 非覆盖元素数**、覆盖元素（连音弧）墨迹宽 = 字形宽；③ 无越界/裁剪异常。
- **通过标准**：零缺字、零无墨迹元素。**这一层是渲染管线的回归护栏**（日后改字体/度量/常量必跑）。

### L2 版式级：元素级模板比对（全库，小时级；可抽样）
- **做法**：PDF 页以 **300 dpi** 栅格化 → 按 `y` 定位该行的**音符行带**（同时用墨迹水平投影找到行界）→
  由首个数字的墨迹高度反推**印刷字号**（缩放因子）→ **从左到右逐元素局部模板匹配**：
  把该元素的字形（单码位逐字形、多码位按墨迹宽 + 0.10em 拼接）渲染成掩膜，在带内做归一化互相关/IOU 搜索，
  匹配位置必须单调递增（允许合并簇：数字+附点/时值线连成一块时仍能各自命中）。
- **判据与阈值**：匹配分 ≥ 0.60 记 `hit`；< 0.60 记 `no_match`（候选差异）；
  整行 **未命中率 ≤ 2%** 且未命中项全部进白名单；另统计「带内有墨迹但无任何预期字形解释」的多余墨迹率 ≤ 5%。
- **产出**：`report_l2.json`（逐行逐元素：命中/未命中/分数/坐标）+ 差异并排图 `diffs/*.png`
  （左：PDF 局部；右：程序版同行；标注未命中元素）。

### L3 视觉兜底（可选，不做判定）
- 对 L2 未消解的差异，用 **`deepseek-flash`（Vision）** 生成「两张图差异在哪」的**文字描述**，
  写进报告辅助人工判读；**判定仍以 L2 的确定性证据为准**（见 `.clinerules` 的图像理解规则）。

## 四、修复与回归闭环

1. 每轮：`L0（全库）→ L1（全库）→ L2（抽样或全库）`，产出 `summary.md` 与分类计数。
2. 按台账逐类修：**数据类**改 DB / 爬虫侧口径（需与爬虫侧脚本同源口径）；**渲染类**改 App。
3. 每修完一类 → **重跑同层比对**，要求该类计数归零（或写入白名单并说明原因）。
4. 全绿后：`flutter analyze` + `flutter test` + `flutter build windows --release` + 实机截图抽查
   （≥5 首，覆盖单页/双页/副歌/连音弧/低音点/附点各一），随代码一起提交。

## 五、运行方式与交付物

```powershell
# L0 数据级全库（分钟级）
python tools/score_selftest.py --stage l0

# L1 渲染自检（--limit N 抽样，0/省略=全库）
python tools/score_selftest.py --stage l1 --limit 30

# L2 版式级元素比对（先抽样确认阈值，再全库）
python tools/score_selftest.py --stage l2 --limit 20

# 指定几首 / 串跑
python tools/score_selftest.py --stage all --hymn 1,2,3,111
```

- **超长任务按全局规则后台跑 + 轮询**：
  `python tools/score_selftest.py --stage l2 > tools\_selftest\l2.log 2>&1`，随后 `Get-Content ... -Tail 10` 轮询。
- **产物目录** `tools/_selftest/`：
  - `report_l0.json` / `report_l1.json` / `report_l2.json`：逐行逐元素明细（机器可读，用于回归对比）；
  - `summary.md`：本轮结论（各级计数、Top 差异清单、与上轮对比）；
  - `rows/*.png`、`diffs/*.png`：渲染图与并排对照图（图片**不入库**：`.gitignore` 掉 `tools/_selftest/`，
    只提交 `summary.md` 与白名单）。

## 六、风险与对策

| 风险 | 对策 |
| --- | --- |
| 印刷 PDF 的乐谱是位图、文本层 advance 被压平 | 内容判定用**文本层码位**（L0）；版式判定用**栅格位图 + 字形模板匹配**（L2），不依赖文本层坐标 |
| 行定位（y 偏移 / 双页 / 多声部） | `y` 在 ±10pt 内搜索最优偏移；双页按 `page_count` 分页取行；只比对 `is_primary=1` 的主旋律行 |
| 模板匹配对缩放敏感 | 由首个数字的墨迹高度反推缩放（±10% 内插微调）；阈值 0.60 且要求匹配位置单调递增 |
| 文本层填充符（`0020`/`3021`）干扰 | L0 统一过滤这两类码位后比对 |
| 视觉模型判定不可复现 | 只用 `deepseek-flash` 生成差异描述，最终判据仍是 L0/L2 确定性证据 |
| 非标素材（无 MMP2005 文本层的简谱 PDF）无字可比 | 比对以 `hymn_score.pdf_path` 为准；抽不到 MMP2005 的首记入白名单（L0 记 `nonstd_pdf`），其数据需单独取证补录或从库中剔除 |
| 字体来源（PDF 内嵌 MMP2005） | 项目内部使用；公开发行前评估字体授权（见 `UI_CONFIRMATION.md` §5.18） |
