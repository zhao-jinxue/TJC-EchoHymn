## 5. 交互行为（最终）

### 5.1 全局快捷键（通用方案）

| 功能 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | 空格 或 Ctrl+P（输入框聚焦时空格放行输入） |
| 下一首 / 上一首 | Ctrl+→ / Ctrl+←（兼 Alt+→/←） |
| 音量增大 / 减小 | Ctrl+↑ / Ctrl+↓（长按连续；同步系统音量） |
| 静音 / 取消静音 | Ctrl+M（同步系统静音） |
| 打开用户手册 | F1（重复触发不叠加） |
| 键盘媒体键 | 播放暂停/上一首/下一首/音量±/静音 |

### 5.2 窗口交互

- 标题栏空白处**拖动窗口**、**双击最大化/还原**；最大化图标随 `Win+↑/↓`、拖到屏幕顶部自动同步。
- 窗口大小变化时内容**等比缩放**（不裁切不变形）；最小客户区 850×890（展开侧栏后 + 栏宽）。

### 5.3 侧栏抽屉

- 顶栏左右按钮展开/收起（窗口加宽 350/600，基座居中）；状态持久化 `showLeft/showRight`，重启恢复。

### 5.4 搜索（编号定位 + 歌名/歌词统一弹窗，v1.5.1）

- 搜索框不变（提示「搜索编号 / 歌名 / 歌词」），回车触发：
  - **纯数字** → 按编号翻页 + 滚动 + 高亮定位（不自动播放）；第二次回车播放并**自动清空搜索框**（S02：防止焦点仍在框内再回车从头重播；空框回车无动作）。
  - **中文** → `HymnSearchService` 同时模糊搜索**歌名 + 歌词**（`Hymn.verses` 全量内存扫描，繁简双向匹配），命中弹出**统一搜索结果弹窗**：
    - 三列表格：编号 / 诗歌名称 / 歌词，每首一行；排序 = 歌名命中在前、歌词命中在后，组内按编号。
    - 歌名命中：名称列关键字**红色加粗**（danger），歌词列默认显示第一节；歌词命中：歌词列显示**第一个命中节**、关键字**主题色加粗**（primary），且**从关键字所在行开窗显示**（前有截断加「…」前缀，S27：保证单元格 3 行内关键字可见、所见即命中点）；双命中同行并存。
    - 单元格显示简体；关键字在简体文本上定位分段加粗；名称最多 2 行 / 歌词最多 3 行省略。
    - **单击行选中**高亮、**双击行**关闭弹窗 + 左栏定位 + 播放 + 清框（沿用音频版本记忆）。
    - **弹窗是唯一播放入口（S11/S24）**：回车从不直接播放；关闭弹窗后再次回车 = 重新弹窗。
  - **无命中**（两类皆空）→ 不弹窗，左栏显示「未找到匹配的诗歌」空态 + Toast。
- × 清空 / 退格删空 → 回分页列表并**强制滚回当前定位行**（S04：`scrollCurrentIntoView(force)` 跳过可见性近似判断 + 滚动统一排帧后，修复列表重建 hasClients 时序与行高 34px 近似误判）。
- 弹窗关闭后焦点回搜索框：桌面端默认**全选**导致光标不可见（S09），已折叠光标到文本末尾，可直接续输新关键字。
- 实现：`lib/services/hymn_search_service.dart`（搜索计算）+ `lib/widgets/hymn_search_dialog.dart`（弹窗）；单元测试 `test/hymn_search_service_test.dart`（18 用例）。

### 5.5 播放与切歌

- 列表内循环切换；切歌高亮联动滚动；播放完成自动下一首；恢复状态不自动播放。

### 5.6 音量（系统双向同步）

- **音量模型（2026-09-01 修复）**：系统音量为唯一响度旋钮，滑条=系统音量镜像，播放器增益恒 100%（静音 0）——修复前应用增益与系统音量叠乘（输出 v²，50% 实际 25%，比系统播放器轻 ~12dB）。无系统通道的平台退化为应用增益模式。

- 播放条控件与快捷键共用单一数据源（`volumeNotifier/mutedNotifier`）实时联动。
- **应用→系统**：滑条/快捷键/静音写回系统音量（Core Audio）。
- **系统→应用**：启动初始化为系统音量；运行时 1s 轮询跟随系统变化。

### 5.7 状态持久化

- 左栏 Tab/二级目录/个人歌单/诗歌编号/音频版本/歌词模式/歌词翻页模式（手动/自动 `lyricAutoMode`）/播放列表位置/侧栏状态/配色 appTheme/字号 fontSizeLevel/启动弹出手册 manualOnStart——**切换即保存**；`state.json`（exe 同级，原子写+串行队列）。

### 5.8 换肤（v1.4.0）

- 标题栏「调色盘」按钮（用户手册左侧）弹出 **5 套配色**菜单（主色圆点+名称+当前✓，名称为全称：晨光蓝 · 经典 等），点击即整体换肤、**即时生效不重启**（MaterialApp 整树重建）。
- 配色写入 `state.json` 的 `appTheme`，启动时恢复；删除/非法值回退默认「晨光蓝 · 经典」。
- 换肤只改颜色，布局、字号、快捷键、弹窗均不变；**8 个 UI 分区用同色相极浅底色区分**（标题栏/顶栏/左栏/右栏/版本栏/播放条/状态栏/歌词区），深色主题下为相近深色层次，所有区域自动切换。

### 5.9 字号（v1.5.0）

- 标题栏「调色盘」**右侧**新增字号按钮（**大小写双 T 图标** format_size，「？」手册左侧），弹出 **4 级字号**菜单（默认 / 中号 / 大号 / 最大，当前项 ✓），点击即切换、**即时生效不重启**。
- 实现 = **全局等比缩放**（`MaterialApp.builder` 内 `Transform.scale`）：所有控件尺寸/位置/字号/图标（含弹窗/菜单/Toast）按系数等比例放大；**最小客户区 850×890 不变**，歌词区为 `Expanded` 自动让位（放大后左栏不够宽可压缩歌词区宽度）。
- 初版系数：默认 ×1.0 / 中号 ×1.3 / 大号 ×1.6 / 最大 ×1.9（2026-08-31 用户调整，集中在 `lib/theme/app_fonts.dart` 一处可调）。
- **歌词区单独处理**：保持「铺满自适应字号」算法为基准，结果乘字号系数（`bodySize × 系数`）；大字号下歌词超出显示区 → 滚动阅读（`SingleChildScrollView` 兜底）。
