## 任务 33（2026-10-25）：决策落档（不跟随系统深色）+ SAF 素材导入

### 提问

（用户）不跟随系统深色，使用软件的配色，B → A（先做 SAF 导入再试用）。

### 解决思路

1. **决策落档**：`跟随系统深色` 在文档里出现 7 处（`ANDROID_PLAN` 5 + UI 确认单 2），
   逐处标注「2026-10-25 裁定不做」—— 避免以后又被当成待办。
2. **SAF 导入的关键取舍**：`audioplayers` 的 `DeviceFileSource` 只接受**文件绝对路径**，
   `content://` URI 无法直接播 → 导入语义定为「**复制到应用私有目录**」，
   复制完成后 DB 里的相对路径自然生效，播放链路零改动。
3. 原生侧（`MainActivity.kt`）：`ACTION_OPEN_DOCUMENT_TREE` + `takePersistableUriPermission`
   + `DocumentFile` 递归复制 + 每 20 个文件 `invokeMethod('importProgress')` + `importDone`。
4. Dart 侧（`media_import.dart`）：通道封装 + 两个广播流；设置页「素材」分组 + 进度对话框（提示重启生效）。

### 最终结果

- **完成结论：F-4 代码完成；SAF 实机点通未完成**
