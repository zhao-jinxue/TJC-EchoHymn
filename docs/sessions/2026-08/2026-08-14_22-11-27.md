## 会话总结

- 本次共处理 **9 个任务**（skills/MCP 环境配置：6 安装/迁移类 + 1 调研问答 + 1 多 skill 请求处理 + 1 全局 MCP 迁移；另含本次日志补写）。
- 关键收获：
  1. **全局 vs 项目级配置边界**：skills 与 MCP 均支持全局/项目两级——个人工具应放全局（`~/.cline/skills/` 与 `%APPDATA%\Code\User\globalStorage\saoudrizwan.claude-dev\settings\cline_mcp_settings.json`），项目专用才放项目 `.mcp.json`；Cline 默认从全局加载。
  2. **第三方 skill 来源可信度**：优先官方/高星组织（Cloudflare 2.9k star、awesome-skills 1.7k star），无法确认来源的宁可不装。
  3. **MCP 与 skill 是两套机制**：skill 是 SKILL.md 指令包（放 skills 目录），MCP 是进程型服务器（注册 mcpServers），安装方式完全不同；预编译二进制可绕开本地工具链缺失。
- 遗留事项：
  - 未安装的 7 个 skill（publish-desktop、amplify-workflow、review-team、unreal-cpp、linear-sdk-scripting、attorney-assist、Cline SDK Skill）待用户提供确切来源后可继续。
  - 最终环境：5 个全局 skills（code-review-skill、simplify-skill、security-audit、deploy-checklist、thesis-writer）+ 7 个全局 MCP + 2 个项目 MCP。
