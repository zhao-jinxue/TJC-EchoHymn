- **关键改动**：

  - `hymn_app/lib/main.dart`：lite（`kHasAudio=false`）不初始化通知权限/媒体会话
  - `hymn_app/lib/services/db_bootstrap.dart`：in-flight Future 复用 + **唯一临时文件名** + rename 竞态容错

  - `hymn_app/lib/widgets/android_manual_sections.dart`：顶栏章节按变体、lite 文案修正
  - `hymn_app/lib/widgets/user_manual_dialog.dart`：473 → 474（3 处）
  - `tools/build_android_release.ps1`：补 `--dart-define=AUDIO_VARIANT=$Variant`
  - `tools/verify_android_device.ps1`（新增）：多视口 × 字号走查脚本
  - `docs/Android/F3_DEVICE_WALKTHROUGH_2026-11-11.md`（新增）：走查报告
- **验证方式**：`flutter analyze` 0 · `flutter test` **77/77**（桌面 golden 未变）· `flutter build windows --release` · 模拟器 15 组合 `overflow=0` · 安装/升级/卸载/重装四步日志 · lite 顶栏「浏览 ·」+ 源考一致 + 474 首列表。
- **遇到的困难**：
  1. 归档正式包是 arm64-only，x86_64 模拟器报 `libflutter.so is for EM_AARCH64` → 改用同代码同签名的 `android-x64` 构建做走查（并在报告中标明环境限制）。
  2. `adb shell grep` 读设备日志会卡死（300s）→ 改为 `adb pull` 到本地再检索。
  3. lite 首启列表为空：日志显示两个 isolate 并发首装 DB 争用 `.tmp` → 用唯一临时名 + 自愈修复；顺带发现 `HomeScreen` 被创建两次（根因待查）。
  4. 系统通知权限对话框用 `input tap` 点击无效 → 改用 `pm grant` 授权后返回。
- **遗留问题**：真机走查 · 替代音频 474 全可播（裁库）· **lite 播放能力定义需用户裁定** · 首启双引擎初始化根因 · 横屏 + 特大字号需滚动 · 320dp 顶栏需横向滑动。

## 会话总结

- 本次共处理 1 个任务（F-3 收尾）
- 关键收获：
  1. **变体标识必须从构建入口注入**：`--dart-define=AUDIO_VARIANT` 缺失会让四个变体运行时全部退化成 `full`；`build_android_release.ps1` 与 `publish_android.ps1` 必须保持一致。
  2. **首启并发是移动端必修课**：同一 `.tmp` 路径 + 两个引擎并发 → `PathNotFoundException` + 空库；临时名唯一 + 竞态容错 + 空库自愈三件套才算稳。
  3. **overlay 控件与「内容可超屏」不能共存**：翻页条改为独立占位后，横屏遮挡问题从根上消失。
- 遗留事项：见 STATE「阻塞 / 待确认」（lite 播放能力裁定、双引擎根因、真机走查、裁库方案）。
