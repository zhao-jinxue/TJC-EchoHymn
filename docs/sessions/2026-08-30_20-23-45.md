# 五套换肤配色 + 换肤机制（v1.4.0）

- 日期：2026-08-30
- 工具链：Cline + DeepSeek API
- 涉及模块：UI 主题 / 标题栏 / 状态持久化 / 文档

## 任务 1：设计 5 套配色方案并提供效果图

### 提问

用户希望「丰富当前软件的界面效果」，期望提供 **5 套不同的配色方案**，要求配色好看且**方便换肤**，并询问能否提供效果图。

### 解决思路

1. **现状盘点**：颜色全部集中在 `hymn_app/lib/app.dart` 的 `AppColors` 静态常量类（17 个语义色槽），被 8 个文件约 170 处引用；另有少量硬编码（`Colors.white`、关闭按钮悬停红、标题栏按钮悬停灰、滚动条滑块灰）。
2. **换肤可行性的关键判断**：只要保持「同一套语义色槽、只换色值」，换肤就是零成本 —— 界面引用色槽名，切换调色板即整体换肤。据此设计 5 套方案，覆盖冷暖/明暗/色相多样化：
   - ① 晨光蓝（默认，与 v1.3.1 一致，零回归）
   - ② 暖阳金 · 圣堂（暖奶油 + 圣金黄 + 橄榄绿，贴合赞美诗气质）
   - ③ 静谧绿 · 草木（鼠尾草绿 + 薄荷白，护眼）
   - ④ 典雅紫 · 暮云（紫罗兰 + 青碧强调，晚祷静谧感）
   - ⑤ 暗夜墨 · 深色（深空灰蓝 + 明亮青蓝，夜读）
3. **效果图方案**：不使用静态 PNG，改为制作**交互式 HTML 高保真预览页** `docs/theme_preview.html`（1800×890 画布 = 基座 850 + 左栏 350 + 右栏 600），忠实还原标题栏/顶栏/三面板/播放条/状态栏，5 套配色一键切换 + 「对比全部」纵览 + 每套调色板明细（色名+hex），可缩放。比静态图更好对比、可长期维护。

### 最终结果

- **完成结论**：5 套配色方案已设计定稿，效果图以 `docs/theme_preview.html` 交付（浏览器打开即可预览）。
- **关键改动**：新增 `docs/theme_preview.html`（CSS 变量 = 语义色槽，与 Flutter `AppPalette` 字段一一对应）。
- **验证方式**：浏览器直接打开预览；色值均按语义对比检查可读性（文字/背景对比度）。
- **遇到的困难**：预览文件较大需分块写入；无。
- **遗留问题**：待用户选择/微调具体色值（改 HTML 与 `app_palette.dart` 两处即可）。

## 任务 2：Flutter 实现换肤机制

### 提问

用户要求配色「方便换肤」——即在应用内可随时切换并持久化。

### 解决思路

1. **架构方案对比**：
   - A. `ThemeExtension`（Flutter 惯用）：需把 170 处 `AppColors.xxx` 改成 `context` 取值，且 `const` 全部失效，改造量大、侵入性强。
   - B. **静态门面 + 当前调色板指针（选定）**：`AppColors` 保留同名静态 getter，内部读「当前调色板」；整棵 MaterialApp 用 `ValueListenableBuilder<AppPalette>` 监听重建，所有引用自动跟随。业务代码改动最小（仅需去掉被波及的 `const`）。
2. **持久化**：`state.json` 新增 `appTheme` 字段，`main()` 启动时恢复，HomeScreen 切换时保存。
3. **入口**：标题栏新增「调色盘」按钮（用户手册左侧），点击弹出 5 套配色菜单（主色圆点 + 名称 + 当前项对勾），点击即切换。

### 最终结果

- **完成结论**：换肤机制实现完成 —— 标题栏调色盘一键切换 5 套配色，重启保持。
- **关键改动**：
  - 新增 `lib/theme/app_palette.dart`：`AppPalette`（19 个语义色槽）+ 5 套预设 + `kThemes` + `themeById` + `ThemeController`（ValueNotifier）。
  - `lib/app.dart`：`AppColors` 由 static const 改为**当前调色板门面**（静态 getter）；`EchoHymnApp` 用 `ValueListenableBuilder` 监听重建 MaterialApp/ThemeData；滚动条滑块色随配色。
  - `lib/main.dart`：启动时读 `state.json` 恢复配色。
  - `lib/services/app_state_service.dart`：`AppState.appTheme` 字段 + `saveAll` 参数。
  - `lib/screens/home_screen.dart`：标题栏新增 `palette_outlined` 换肤按钮 + `_showThemeMenu`（showMenu 5 项）+ `_switchTheme`；`_saveState` 带配色；`_WindowButton` 悬停灰改 `AppColors.windowBtnHover`。
  - `lib/widgets/user_manual_dialog.dart`：手册新增换肤说明。
  - 76 处含 `AppColors` 的 `const` 表达式经 `tools/_fix_const.py` 脚本去 `const`（分析器逐项校正）。
- **验证方式**：`flutter analyze` 0 issues；`flutter build windows --release` 成功；启动冒烟测试正常（日志「主题: 晨光蓝」，数据库 474 首加载、无异常）。
- **遇到的困难**：`AppColors` 变动态后约 76 处 `invalid_constant`，手改量大 → 写一次性脚本按「const 表达式内含 AppColors」自动去 const，再用 analyze 收敛剩余 lint。
- **遗留问题**：待实机逐一验证 5 套配色的视觉细节与弹出菜单交互；可后续把「调色盘」入口补充到用户手册快捷键表或测试清单。
