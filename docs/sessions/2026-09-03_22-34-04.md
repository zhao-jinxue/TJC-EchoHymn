## 任务 3：Windows 安装包制作（向导 + 誓言页 + 加密压缩 + 卸载）

### 提问

项目主体完成、release 正常，现制作 Windows 安装包：①管理员提权 ②首页环境兼容性检查 ③第二页安装位置（默认 D:\Program Files\EchoHymn）④第三页宗教宣誓词抄写校验（不可复制、失败不安装，宣誓词提供 5 版供选）⑤压缩 ⑥加密防解包 ⑦卸载程序。要求先以发布者视角审核补全再实施。

### 解决思路

- **发布者补全 10 项**（编号 9~18）：代码签名（首期不签+文档说明 SmartScreen）、环境检查项清单、升级安装保留用户数据、**安装目录 ACL 授权**（state.json/logs 写在 exe 同级，Program Files 下普通用户写不进——分发后致命项）、快捷方式、静默安装参数、版本单源注入、SHA256 旁文件、卸载残留处理、构建脚本化。
- **选型**：Inno Setup 6（免费、自定义向导页成熟）+ **AES-256 加密 7z 单一载荷**（加密头隐藏文件清单，密钥 XOR 混淆内嵌；"不可破解"在逻辑上不成立——安装包必须可被任何用户免密安装，定位是防随意解包）。
- **数据瘦身**（用户拍板）：DB 引用扫描显示 3631 个素材中 3014 个（3.11GB）被数据库实际引用，617 个（0.14GB，旧音频+json 边车）无引用 → 打包清单只收引用文件（`installer/payload_manifest.txt`）。
- **宣誓词**：用户选定"祷告版"；校验=去空白+半角标点归一全角后全文比对；展示框/输入框通过 KeyDown 拦截 Ctrl+C/V/X/A 与 Shift+Insert 实现"不可复制、不可粘贴"。
- **升级/卸载数据策略**：升级时备份并还原用户 `tjc_hymn.db`（个人歌单）；卸载弹窗询问是否保留个人数据（默认保留，静默=保留）。
- **中文语言**：Inno 6.7 发行包与网络镜像均拿不到 ChineseSimplified.isl → 写 `make_chinese_isl.py` 离线从 Default.isl 生成（只替换已存在键防编译报错，未命中键回退英文）。

### 最终结果（进行中，构建后补全）

- 已产出工程：`installer/echohymn.iss`、`installer/prepare_staging.py`、`installer/make_payload.py`、`installer/make_chinese_isl.py`、`tools/build_installer.ps1`、`tools/scan_db_refs.py`、`docs/INSTALLER.md`
- 环境：Inno Setup 6.7.3（UAC 提权安装成功）、py7zr 1.1.3
- **本轮实机测试抓出的 4 个关键坑**（全部已修复并复验）：
  1. **清单缺运行时文件**：payload_manifest 只覆盖 Hymn_Downloads，首版 prepare_staging 把 `tjc_hymn.db`/`flutter_assets`/`icudtl.dat` 全过滤掉了（安装显示成功但程序必闪退）→ 规则改为"data 内仅 Hymn_Downloads 按清单过滤，其余全收"（3023→3038 文件）。
  2. **AppId 花括号转义**：`AppId={{{#GUID}}}` 会多出尾 `}`（Inno 只转义 `{{`→`{`，`}}` 不转义），导致卸载注册表键变形、旧版本检测失效 → 正确写法 `{{{#GUID}}`（尾单括号）。
  3. **静默模式誓言互锁**：/VERYSILENT 下 NextButtonClick 仍被调用，空输入校验直接把安装拦死（EAbort）→ 静默通道跳过誓言校验（环境检查仍生效）。
  4. **ExtractArchive 两连坑**：① `FullPaths=False` 会把归档内路径**剥掉目录拉平**（3040 文件全散根目录）；② 置 True 后报 `0x80070005`——微型用例定位元凶是 py7zr `writeall(arcname=".")` 产生的 **"." 根条目** → make_payload 改为逐文件写入（无点根、无目录条目），Inno 自动建目录。
- 其他修复：`SplitConst`/`DrivePresent`/`NextButtonEnabled`/`faDirectory` 等标识符按 6.7.3 实际 API 替换；ExtractArchive 是 procedure（CHM 反编译确认签名）；载荷 preset 9→1（30 分钟→15 分钟）+ ISCC `Comp=none`（加密数据不再压）；中文语言文件离线生成器（网络全阻时的回退，42 键翻译）；后台链式脚本进程被杀后的级联误删防护（清理加 payload 存在性条件）。
- 验证件（已通过）：AES+加密头 7z × is7zxa enhanced 模式解包（含中文/空格文件名与子目录）；静默安装 3040 文件 + 注册表 + ACL 授权（BUILTIN\Users:(OI)(CI)M）；卸载清全部程序文件且保留个人数据金丝雀、注册表自清。
