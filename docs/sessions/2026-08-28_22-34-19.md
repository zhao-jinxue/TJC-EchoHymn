## 任务 5：批 1 · 数据/底层 NG 修复（A01/A03/A04/J04/G11/J06/K12/K13）

### 提问

按批 1 计划修复：默认状态/首次启动（A01+A03+J04）、状态恢复（A04+J06+G11）、数据库路径（K12/K13）。

### 解决思路

- **A01/A03/A04/J04 根因**：`AppStateService.load()` 在 state.json 缺失时调用 `_migrateFromLegacy()` 从旧版本 `%APPDATA%` Roaming 迁出过时状态（交托恩主/145），污染首次启动与删库后启动，恢复目标歌曲不在子目录 → `currentHymn` 为 null → 显示"请在左侧选择"。→ **移除 legacy 迁移**（v1.0.4 前已完成使命）。
- **G11/J06 根因**：`HymnListPanel.restoreSaved` 盲目优先 `anchor.playlistIndex`（旧页码快照）→ 高亮与当前播放错位。→ **改为优先按当前播放歌曲定位**，playlistIndex/hymnNumber 仅作兜底。
- **K12/K13 根因**：`_locateDesktopDataRoot` 向上 12 层找 db，发布包内删库后穿透到仓库根误命中旧库。→ **发布包目录（echohymn_win_* 前缀）禁止向上查找**；同时发现 Flutter 构建产物 `data/` 是引擎资产目录（无 db），定位判据必须用「含 tjc_hymn.db」而非目录存在。
- **空库崩溃问题**：删库后 sqlite3.open 重建空库 → 无 tjc_hymn 表 → `SqliteRepository` 查询抛异常 → 初始化失败。→ **`hasCoreTables` 探测 + 各查询无表返回空列表**（空态而非崩溃）。

### 最终结果

- **关键改动**：
  - `lib/services/app_state_service.dart`：移除 `_migrateFromLegacy`，state.json 缺失返回默认状态
  - `lib/services/app_paths.dart`：`_locateDesktopDataRoot` 发布包禁向上 + 以 db 文件为判据
  - `lib/services/sqlite_repository.dart`：`hasCoreTables` 探测，无核心表时查询返回空
  - `lib/widgets/panels/hymn_list_panel.dart`：`restoreSaved` 优先当前播放歌曲
- **验证方式**：flutter analyze 0 issues；构建成功；开发场景冒烟（删 state.json 启动 → 默认加载第 1 首、state.json 写入 hymnNumber=1/playlistIndex=0/leftTab=hymnList）；发布包场景模拟（echohymn_win_* 目录删 db → 定位应用支持目录 → 空库容错初始化完成不崩溃）
