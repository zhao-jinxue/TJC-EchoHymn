## 任务 3：release 目录命名规则改为时间戳前置（可按名称排序）

### 提问

release 的版本目录名称组合不对，无法通过名称排序找到最新版本（日期信息在目录名称最右侧）。将命名规则改为 `echohymn_win_20260821-232036_850cba1`，并发布最新版本。

### 解决思路

- 旧命名 `echohymn-win-<短哈希>-<时间戳>`：时间戳在最后，名称排序不能直接反映版本新旧。
- 新命名 `echohymn_win_<时间戳>_<短哈希>`：时间戳前置 + 下划线分隔，**名称排序 = 时间排序**（最新排最前）。
- 同步调整：脚本匹配模式 `echohymn-win-*` → `echohymn_win_*`；旧版本清理排序由 `CreationTime` 改为 `Name`（新命名下更可靠）；更新 4 份文档（SESSION_SUMMARY/DEPLOY/RECOMMENDED_TOOLS/README）；手动发布验证后清理旧命名目录。

### 最终结果

- **完成结论**：命名规则切换成功，最新版本已按新规则发布。
- **关键改动**：
  - `tools/publish_windows.ps1`：`$PkgName = "echohymn_win_${ts}_${commitShort}"`；匹配/清理均用 `echohymn_win_*`；旧版本排序改 `Sort-Object Name -Descending`
  - `docs/SESSION_SUMMARY.md` / `docs/DEPLOY.md` / `docs/RECOMMENDED_TOOLS.md` / `README.md`：命名规则同步更新
  - 清理旧命名目录 4 个（`echohymn-win-68a6bec/850cba1/a557003/f6da163`）
