### UI 布局调整（本轮）

用户反馈（提供两张截图 + 明确需求）：

1. **基座画面尺寸**：1115×891 → **850×890**（基座画面 = 最简播放画面，歌单列表/诗歌源考两个左右栏目都依托此画面展开）
2. **歌词显示区背景**：给纯歌词显示区域添加背景颜色，与左右两侧形成**轻微色差**，使用户能感知歌词实际显示区域大小

### 解决方案

1. **窗口尺寸**（`hymn_app/windows/runner/main.cpp`）：初始尺寸 1280×720 → **850×890**
   - `win32_window.cpp`：最小宽度 1132 → **850**（否则初始 850 会被系统强制拉回 1132）；最小高度保持 700

2. **基座形态默认收起侧栏**（`hymn_app/lib/screens/home_screen.dart`）：
   - `_showLeft` / `_showRight` 默认 `true` → **`false`**（启动即为基座画面；左右侧栏收起后展开按钮为蓝底）
   - 850 宽下展开侧栏会挤占歌词区，故以「收起」为默认基座形态

3. **歌词区背景色差**（`hymn_app/lib/app.dart` + `hymn_app/lib/widgets/hymn_display.dart`）：
   - 新增 `AppColors.lyricsBg = Color(0xFFFDF8EE)`（暖白）
   - `_buildLyrics` 外包 `Container(color: AppColors.lyricsBg)`，与两侧冷灰 #F5F6FA 形成轻微色差
