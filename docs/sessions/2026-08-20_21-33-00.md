### UI 布局调整（本轮）

用户反馈（提供两张截图 + 明确需求）：

1. **基座画面尺寸**：1115×891 → **850×890**（基座画面 = 最简播放画面，歌单列表/诗歌源考两个左右栏目都依托此画面展开）
2. **歌词显示区背景**：给纯歌词显示区域添加背景颜色，与左右两侧形成**轻微色差**，使用户能感知歌词实际显示区域大小

### 解决方案

1. **窗口尺寸**（`hymn_app/windows/runner/main.cpp`）：初始尺寸 1280×720 → **850×890**
   - `win32_window.cpp`：最小宽度 1132 → **850**（否则初始 850 会被系统强制拉回 1132）；最小高度保持 700

2. **基座形态默认收起侧栏**（`hymn_app/lib/screens/home_screen.dart`）：
   - `_showLeft` / `_showRight` 默认 `true` → **`false`**（启动即为基座画面；左右侧栏收起后展开按钮为蓝底）
   - 850 宽下展开侧栏会挤占歌词区，故以「收起」为默认基座形态

3. **歌词区背景色差**（`hymn_app/lib/app.dart` + `hymn_app/lib/widgets/hymn_display.dart`）：
   - 新增 `AppColors.lyricsBg = Color(0xFFFDF8EE)`（暖白）
   - `_buildLyrics` 外包 `Container(color: AppColors.lyricsBg)`，与两侧冷灰 #F5F6FA 形成轻微色差

### 第二轮反馈修正（DPI 物理像素 + 抽屉式侧栏）

用户反馈（两张新截图）：

1. 启动后实机尺寸 1045×1104、最小 833×691——**不是**理想的 850×890（原因：用户屏幕 DPI≈125%，逻辑 850×890 被缩成物理 1045×1104）
2. **展开侧栏 = 窗口整体变宽**（非挤压歌词区）：左栏物理 350px、右栏物理 600px；展开后 1200 / 1450 / 1800px

### 修正方案（物理像素驱动）

- **窗口客户区改为物理像素**：`main.cpp` `SetClientSize(850,890)` + `SetMinClientSize(850,890)`（`win32_window.cpp` 用 `AdjustWindowRectEx` 换算外框，保证客户区精确 850×890 物理像素，与 DPI 无关）
- **MethodChannel**（`echo_hymn/window`）：`flutter_window.cpp` 注册 `setClientSize`；Dart 侧 `home_screen.dart` 展开/收起侧栏时调用——窗口整体变宽（850+350+600，全展开 1800）
- **侧栏宽度 DPI 换算**：左栏 350/dpr、右栏 600/dpr 逻辑像素（保证各 DPI 下物理宽度恒为 350/600）
- 头文件补充 `method_channel.h`/`standard_method_codec.h` include（首次构建报 C2039，已修复）
