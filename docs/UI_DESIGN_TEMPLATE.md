## 二、整体布局框架（自上而下四栏 + 抽屉式侧栏）

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [♫ EchoHymn · 聆听赞美诗]                [？][—][□][×]  ← 自绘标题栏 30px │
├──────────────────────────────────────────────────────────────────────────┤
│ [◀]             当前歌曲（第 N 首《标题》）                 [▶]  ← 顶栏 40px │
├──────────┬───────────────────────────────────────────────┬───────────────┤
│ 左栏 350  │  版本栏：[钢琴版][人声版]        [歌词][简谱][五线谱] 44px  │ 右栏 600  │
│ 诗歌列表  │  歌词 / 简谱 / 五线谱 显示区（等比缩放铺满）             │ 诗歌源考    │
│ 默认歌单  │                                                  │             │
│ 个人歌单  │  播放条：进度条                                       │             │
│          │   [🔊][───][50%]   [⏮][⏯][⏭]  [👥]              │             │
├──────────┴───────────────────────────────────────────────┴───────────────┤
│                   底部状态栏：编号 · 歌名 · 词曲 · 进度        ← 30px       │
└──────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 高度/宽度 | 背景 | 内容与行为 |
| --- | --- | --- | --- |
| **自绘标题栏** | 30px | #FFFFFF | 左侧 logo（蓝色音符 22×22）+ 应用名；右侧窗口按钮组（用户手册/最小化/最大化·还原/关闭，42×30）；**整条空白处可拖动窗口、双击最大化/还原**；与顶栏间 1px 分隔线 |
| **顶栏（功能栏）** | 40px | #FFFFFF | 左端 = 展开/收起**左栏**按钮（60×30）；右端 = 展开/收起**右栏**按钮；中央 = **当前播放/选中歌曲**（“第 N 首《标题》”，繁体转简体，切歌自动刷新；无歌时显示应用名） |
| **左侧栏（抽屉）** | 宽 350px | #F5F6FA | 三个 Tab（诗歌列表 / 默认歌单 / 个人歌单）；由 `LeftPanel` 基类 + 三个子类实现；默认收起，展开时窗口向左加宽 |
| **内容区** | 剩余 | #FAFBFC | 版本栏 + 显示区 + 播放条（见下） |
| 版本栏 | 44px | #FFFFFF | 「钢琴版｜人声版」音频版本按钮组 + 「歌词/简谱/五线谱」显示模式按钮组 |
| 显示区 | 剩余 | #FDF8EE（歌词） | 歌词（字号按区域自动铺满）/ 简谱 / 五线谱（`InteractiveViewer` 可缩放拖动） |
| 播放条 | ~98px | #FFFFFF | 上层 = 进度条（可拖动跳转，显示位置/总时长）；下层 = 控制行：**左侧音量控件**（静音图标 + 滑条 + 百分比）、**居中**上一首/播放·暂停/下一首、**右侧**人声版本 👥 按钮（>1 时显示） |
| **右侧栏（抽屉）** | 宽 600px | #F5F6FA | 当前诗歌**源考资料**（source_info 繁体转简体，可滚动）；默认收起，展开时窗口向右加宽 |
| **底部状态栏** | 30px | #FFFFFF | 当前歌曲信息（第 N 首 · 标题 · 词：作词 · 曲：作曲）+ 播放进度（位置/总时长 · 百分比）；上方 1px 分隔线 |

> **窗口与侧栏的关系**：左右栏为**抽屉式**——展开时窗口整体加宽（左 +350 / 右 +600），
> 基座画面（歌词区 850 宽）中心始终对齐屏幕工作区中心；最小窗口客户区 = 850×890 + 已展开栏宽。

## 三、窗口 / 页面 / 弹窗清单

### 3.1 主窗口（HomeScreen）

- **用途**：应用主界面，承担全部日常操作。
- **分块**（自上而下）：标题栏 → 顶栏 → 内容区（版本栏/显示区/播放条）→ 状态栏；左右侧栏按需抽屉式展开。
- **交互行为**：
  - 标题栏空白处按住拖动窗口；双击最大化/还原；右侧窗口按钮执行最小化/最大化·还原/关闭。
  - 顶栏左右按钮展开/收起侧栏（窗口同步加宽/变窄，基座永远居中）。
  - 左侧栏三个 Tab 切换；列表点击诗歌 → 播放并联动高亮滚动。
  - 搜索框定位跳转；播放条控制播放/切歌/进度/音量。
  - 全局快捷键（见「六、交互」）在任意界面可用。

### 3.2 用户手册弹窗

- **用途**：展示软件介绍、操作说明、快捷键说明。
- **打开方式**：标题栏「？」按钮 或 按 `F1`。
- **尺寸**：≤560×560，圆角 12。
- **布局**：标题「用户手册」+ ✕ 关闭 → 分隔线 → 滚动内容区：
  - **软件介绍**：应用简介（474 首、离线、钢琴版/人声版、简谱/五线谱、歌单、状态记忆）。
  - **操作说明**：标题栏/顶栏/左侧栏/搜索定位/版本切换/显示模式/播放控制（含音量双向同步）/状态栏。
  - **快捷键说明**：与全局快捷键实现一致的功能-快捷键表。
- **交互**：`Esc` 或右上角 ✕ 关闭；点击遮罩关闭；**重复触发（F1/？）不叠加弹窗**；弹窗打开时全局快捷键（播放/切歌/音量）仍生效。

### 3.3 个人歌单创建 / 编辑弹窗（复用）

- **用途**：创建新歌单；在「个人歌单」Tab 点修改时复用（含删除歌单）。
- **尺寸**：520×420，圆角 12。
- **布局**：标题 → 歌单名称输入框（**限 30 字**）→ 搜索框（编号/标题，回车或按钮搜索）→ 已添加诗歌列表（每项 = 编号 + 标题 + 减号，点击移除；按编号去重）→ 底部「取消」「保存」按钮。
- **交互**：搜索命中 → 弹出「诗歌搜索结果弹窗」选择加入；名称重名检查；保存写入数据库并刷新个人歌单；编辑保存后同步播放顺序。

### 3.4 诗歌搜索结果弹窗

- **用途**：歌单创建/编辑时，从搜索结果中挑选诗歌加入歌单。
- **布局**：标题「诗歌展示」→ 搜索结果列表（每行 = 编号 + 标题 + 「添加」按钮）→ 关闭。
- **交互**：点「添加」→ 该诗加入当前歌单并出现在已添加列表；Toast 就地提示。

## 六、交互与动效

### 1. 全局快捷键（通用方案）

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 播放 / 暂停 | **空格** 或 **Ctrl+P** | 输入框聚焦时空格放行输入 |
| 下一首 / 上一首 | **Ctrl+→** / **Ctrl+←**（兼 Alt+→/←） | 列表内循环切换，高亮联动 |
| 音量增大 / 减小 | **Ctrl+↑** / **Ctrl+↓** | 长按连续调节；同步写回系统音量 |
| 静音 / 取消静音 | **Ctrl+M** | 同步系统静音 |
| 打开用户手册 | **F1** | 已打开时重复触发不叠加 |
| 键盘媒体键 | 播放暂停/上一首/下一首/音量±/静音 | 直接控制 |

> 快捷键实现：根 `Focus` 包裹 `MaterialApp`，任意焦点（含弹窗）事件冒泡统一处理；
> 切换类动作忽略长按重复；音量允许长按。

### 2. 窗口与标题栏交互

| 场景 | 行为 |
| --- | --- |
| 拖动标题栏空白 | 窗口移动；最大化状态拖动自动还原为浮动窗口 |
| 双击标题栏空白 | 最大化 / 还原切换 |
| 最小化 / 最大化·还原 / 关闭 | 标题栏按钮；最大化图标随 `Win+↑/↓` 或拖到屏幕顶部自动同步 |
| 调整窗口大小 | 内容 **等比缩放**（`Transform.scale`，不裁切不变形）；不能小于最小尺寸 |
| 最大化 | 内容等比放大铺满；左右侧栏正常显示 |

### 3. 侧栏抽屉

- 顶栏左右按钮展开/收起侧栏；展开时窗口加宽（左 350 / 右 600），基座画面居中不动。
- 展开/收起状态持久化到 `state.json`（`showLeft/showRight`），重启自动恢复。

### 4. 搜索（定位语义，非过滤）

- 输入**编号**：即时定位并翻页滚动高亮，不自动播放；按回车播放。
- 输入**标题**：显示匹配列表供点击选择（点击播放）。
- 点「×」：清空并保持当前定位结果。

### 5. 播放与切歌

- 播放列表内**循环切换**（上一首/下一首/播放完成自动下一首）；快速连点有防抖。
- 切歌后左栏高亮**联动滚动**到可视区（避开搜索框/标题栏）。
- 播放完成自动切下一首；恢复状态时不自动播放。

### 6. 音量（与系统双向同步）

- 播放条音量控件（图标/滑条/百分比）与快捷键共用 `volumeNotifier/mutedNotifier` 单一数据源。
- **应用 → 系统**：滑条/快捷键/静音变化写回 Windows 系统音量（Core Audio）。
- **系统 → 应用**：启动初始化为系统音量；运行时 1s 轮询跟随系统音量面板/媒体键变化。

### 7. 状态持久化

- 左栏 Tab / 二级目录 / 个人歌单 / 诗歌编号 / 音频版本 / 歌词模式 / 播放列表位置 / 侧栏展开状态——**切换即保存**，下次启动恢复（恢复不自动播放）。

### 8. 动效

| 场景 | 描述 |
| --- | --- |
| 页面切换 | 直接切换 |
| 按钮按下 | 缩小 0.98 + 变深 |
| 数据加载 | 居中转圈 |
| 数据为空 | 大图标 + 「暂无数据」 |
| 数据出错 | 文案 + 「重试」 |
| 暗色模式 | 不需要 |

## 七、响应式 / 多窗口

| 场景 | 行为 |
| --- | --- |
| 最小窗口 | 客户区最小 **850×890** 物理像素（`WM_GETMINMAXINFO`）；展开侧栏后最小尺寸 = 850×890 + 已展开栏宽 |
