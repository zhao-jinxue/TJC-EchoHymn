## 三、页面/窗口清单

> 列出程序包含的所有**页面 / 窗口 / 弹窗**，每个都按下面的模板单独描述。

### **页面名称：个人歌单创建弹窗**

#### 1. 页面用途

创建个人歌单

#### 2. 页面布局（自上而下、自左而右分块）

- 顶部 ：标题「个人歌单创建」
- 歌单名称输入框
- 搜索框
- 中部 ：可滚动列表（每一项 = 编号 + 标题 + 减号）
- 按钮区域 ：取消按钮、创建按钮

#### 3. 每块区域的组件细节

| 页面组件 | 功能说明 |
| --- | --- |
| 顶部 | 显示标题 |
| 歌单名称输入框 | 输入歌单名称，有30个字数限制 |
| 搜索框 | 输入诗歌编号、诗歌名称，点击搜索按钮或回车，出现诗歌弹窗 |
| 中部 | 可滚动列表，显示已经添加的诗歌，点击减号，可删除已添加的诗歌 |
| 按钮区域 | 取消按钮，创建按钮，点击创建后，数据写入数据库，并回到个人歌单显示栏目 |

#### 4. 交互行为

使用通用软件的默认方式

### **页面名称：诗歌弹窗**

#### 1. 页面用途

创建个人歌单

#### 2. 页面布局（自上而下、自左而右分块）

- 顶部 ：标题「诗歌展示」
- 诗歌名称区域
- 歌词区域
- 按钮区域 ：取消按钮、添加按钮

#### 3. 每块区域的组件细节

| 页面组件 | 功能说明 |
| --- | --- |
| 顶部 | 显示标题 |
| 诗歌名称区域 | 编号 + 诗歌名称 |
| 歌词区域 | 展示诗歌的简谱歌词 |
| 按钮区域 | 取消按钮，添加按钮，点击添加后，诗歌加入刚创建的个人歌单中，并在列表中显示 |

#### 4. 交互行为

使用通用软件的默认方式
