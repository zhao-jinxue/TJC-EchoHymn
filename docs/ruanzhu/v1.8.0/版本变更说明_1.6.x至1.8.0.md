## 二、界面差异要点（对照说明书/截图口径）

1. 版本栏右侧模式按钮为四个：**歌词 / 曲谱 / 简谱 / 五线谱**；
2. 「曲谱」= 简谱网格：单声部主旋律 + 当前节一行歌词同列对齐，底部"第 k / N 节"翻页条、
   右上"手动/自动"（自动跟随播放切节），内容不足一屏整块垂直居中；
3. 「简谱」= 印刷简谱扫描图（Ctrl+滚轮缩放、滚轮滚动）；「五线谱」= 五线谱扫描图；
4. 歌词页：一页一节 + 底部翻页条 + 整块垂直居中（1.6.2 起）；
5. 关闭行为（1.8.0 起）：首次点关闭按钮弹窗选择「直接关闭 / 进入系统托盘」，选择记忆；
   进托盘后窗口隐藏、音频继续播放，托盘图标左键恢复、右键菜单可退出；
   用户手册底部新增「重选关闭行为」按钮。

## 三、数据差异要点

1. 表结构：删除 `hymn_score`、`hymn_score_line`、`hymn_score_lyric`、`hymn_score_char`、
   `hymn_codepoint_map`；新增 `jianpu_score`(474)、`jianpu_row`(21819)、`jianpu_cell`(321703)；
2. 谱面形态：由"PDF 抽取的码位序列"改为"网格（行 × 列，列 = 拍点）"，源为四部合唱谱，
   程序按第一声部渲染；
3. 库体积：8.5 MB → 26.7 MB（谱面网格入库）；
4. 安装包：主体（v1.7.4 时 38.8 MB）+ 素材 2.97 GB 双产物；v1.8.0 重新构建。

  全程序 11002 行 / 221 页）；
- 软件说明书已按 **V1.8.0** 重写（11 章体例，含曲谱网格版式图 2 幅与关闭行为章节）；
