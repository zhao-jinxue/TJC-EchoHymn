## 生成器重跑口径

版本升级后只需改 `pubspec.yaml` 的 `version`，然后：

```bash
python tools/make_ruanzhu_source.py    # 源程序鉴别材料（前后各 30 页 × 50 行）
python tools/make_ruanzhu_manual.py    # 软件说明书（页眉版本自动跟随）
```

两份产物的页眉版本号自动跟随 pubspec，保证"材料版本 = 程序版本"。
