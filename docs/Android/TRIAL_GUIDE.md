# EchoHymn Android 试用指南（v1.9.0 · 内部试用版）

> 本文件面向**试用者**（就是你）。只讲「怎么装、能验什么、哪里还没做」。
> 完整背景见 `docs/Android/ANDROID_PLAN.md`、进度见 `docs/Android/STATE.md`。

## 一、安装包在哪

```
release/android/echohymn_android_<时间戳>_<短sha>/
├── EchoHymn-full-v1.9.0-<sha>.apk    ← 全量音频版（com.echohymn.app）
├── EchoHymn-piano-v1.9.0-<sha>.apk   ← 钢琴版（.piano）
├── EchoHymn-vocal-v1.9.0-<sha>.apk   ← 人声版（.vocal）
├── EchoHymn-lite-v1.9.0-<sha>.apk    ← 读谱版（.lite，**无播放功能**）
├── SHA256SUMS.txt
└── BUILD-INFO.txt
```

四个包 `applicationId` 互异，**可以同时安装**。

安装：`adb install -r <apk>`，或把 apk 传到手机点开安装（需允许「未知来源」）。

## 二、⚠️ 必须先知道的能力边界

| 项 | 现状 |
| --- | --- |
| **内置音频** | 仅有 **12 首样本音频**（22 个文件 / 18.76 MB），用于出厂即可播放验证 |
| **完整曲库** | 需把 `data/Hymn_Downloads`（**3.25 GB**）拷到手机，再从「设置 → 素材 → 选择目录」导入（会复制到应用私有目录，需数分钟） |
| **替代音频（已核对）** | 导入完整素材后：**full / piano / vocal 三变体 474 首全部可播**；piano 替代 1 首（`249`→人聲版）、vocal 替代 11 首（`3`/`389`→四部合唱版，其余 9 首→鋼琴版）。核对脚本：`tools/verify_hymn_media_coverage.py` |
| **lite（读谱版）** | **完全没有播放功能**（无播放条/进度/音量/音频按钮/通知栏控制）；只提供歌词 + 简谱/五线谱扫描图 + 分类/歌单 |
| 扫描图 | 12 首样本有图；其余曲目需同上导入完整素材（约 0.5 GB 图片） |

也就是说：**不导入素材时，主要验 UI 与系统集成；导入后验完整曲库。**

## 三、这版重点验什么（推荐顺序）

1. **布局**：竖屏（顶栏 56 / 合并行 44 / 播放条）→ 横屏（双栏 + 播放条单行）→ 旋屏不丢状态
2. **左抽屉三 Tab**（诗歌列表 / 默认歌单 / 我的歌单）+ 右抽屉（源考）；左右互斥、返回键只关抽屉
3. **三模式页**：歌词 / 简谱 / 五线谱（**Android 无「曲谱」模式**，仅 Windows 桌面版有）
   - 扫描图支持双指缩放（上限 3×、双击复位）、右上角 ＋/－ 按钮
4. **搜索页**（顶栏 🔍）：输入编号定位、中文关键字模糊搜索
5. **设置页**（顶栏 ⋮ → 设置）：配色 5 套 / 字号 3 档（标准·大·特大）点选即生效、深色谱面「暗化/原色/反色」、素材导入、用户手册
6. **歌单**：新建/修改（全屏页）、加歌、删除（二次确认）
7. **系统集成**：播放后**通知栏/锁屏出现媒体卡片**、**蓝牙耳机/媒体键**可控制、来电或他 App 播放时**自动暂停**
8. **变体**：lite **完全没有播放条**；piano/vocal **没有版本切换按钮**；piano 第 249 首 / vocal 第 3·389 首等 11 首应有「替代」提示且能正常出声

## 四、已知问题（不用重复报）

| 问题 | 说明 |
| --- | --- |
| 不导入素材时只有 12 首能播 | 设计如此（样本内置 + SAF 导入） |
| 首启日志出现两条「HomeScreen 初始化」 | 两个引擎并发初始化（已知）；DB 已做并发兜底，**无功能影响** |
| 通知卡片**内容**可能不完整 | 只验证了 `importance=DEFAULT` 与 MediaSession 存在，卡片排版未目视 |
| 30 分钟后台播放 | 未做长时实测 |
| 横屏 + 特大字号 | 歌词需纵向滚动（翻页条已不再遮挡） |
| 320dp 极窄屏 | 顶栏模式按钮行需横向滑动才能看到「五线谱」 |
| 深色「跟随系统」 | **不做**（2026-10-25 裁定：配色完全由软件 5 套色板决定） |

## 五、怎么反馈

按优先级记，附上**机型 + 操作步骤 + 截图**：

- **P0**：崩溃 / 装不上 / 数据错乱（如 474 首查不到）
- **P1**：功能不可用（按钮点不动、播放失败、返回键行为异常）
- **P2**：样式/文案/间距不合适

日志位置：`adb shell run-as com.echohymn.app cat files/logs/app_*.log`（或 lite 版换包名）。
