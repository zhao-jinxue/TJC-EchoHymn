# EchoHymn Android 试用指南（v1.8.5 · 内部试用版）

> 本文件面向**试用者**（就是你）。只讲「怎么装、能验什么、哪里还没做」。
> 完整背景见 `docs/Android/ANDROID_PLAN.md`、进度见 `docs/Android/STATE.md`。

## 一、安装包在哪

```
release/android/echohymn_android_trial_<时间戳>_<短sha>/
├── EchoHymn-full-v1.8.5-<sha>.apk    ← 全量音频版（com.echohymn.app）
├── EchoHymn-piano-v1.8.5-<sha>.apk   ← 钢琴版（.piano）
├── EchoHymn-vocal-v1.8.5-<sha>.apk   ← 人声版（.vocal）
├── EchoHymn-lite-v1.8.5-<sha>.apk    ← 读谱版（.lite，无音频）
└── SHA256SUMS.txt
```

四个包 `applicationId` 互异，**可以同时安装**。

安装：`adb install -r <apk>`，或把 apk 传到手机点开安装（需允许「未知来源」）。

## 二、⚠️ 必须先知道的能力边界

| 项 | 现状 |
| --- | --- |
| **音频** | 包内只有 **12 首样本音频**（22 个文件 / 18.76 MB）。**其余 462 首点播放会失败** |
| 原因 | `ANDROID_PLAN §7.5` 定的是「样本内置 + 外部导入（SAF）」，**SAF 导入尚未实现** |
| 曲谱/歌词/扫描图 | 12 首样本有扫描图；其余曲目**有数据但无图**（同素材来源） |

也就是说：**这版主要验 UI 与系统集成，不是验曲库完整性。**

## 三、这版重点验什么（推荐顺序）

1. **布局**：竖屏（顶栏 56 / 合并行 44 / 播放条）→ 横屏（双栏 + 播放条单行）→ 旋屏不丢状态
2. **左抽屉三 Tab**（诗歌列表 / 默认歌单 / 我的歌单）+ 右抽屉（源考）；左右互斥、返回键只关抽屉
3. **四模式页**：歌词 / 曲谱（按小节分页，翻页条显示「第 k/N 页（第 a~b 小节）」）/ 简谱 / 五线谱
   - 扫描图支持双指缩放（上限 3×、双击复位）、右上角 ＋/－ 按钮
4. **搜索页**（顶栏 🔍）：输入编号定位、中文关键字模糊搜索；单击 = 选中并播放
5. **设置页**（顶栏 ⋮ → 设置）：配色 5 套 / 字号 4 档 **点选即生效**、深色下谱面「暗化/原色/反色」、用户手册、启动显示手册
6. **歌单**：新建/修改（全屏页）、加歌、删除（二次确认）
7. **系统集成**：播放后**通知栏/锁屏出现媒体卡片**、**蓝牙耳机/媒体键**可控制、来电或他 App 播放时**自动暂停**
8. **变体**：lite 版应**完全没有播放条**；piano/vocal 版**没有版本切换 chips**

## 四、已知问题（不用重复报）

| 问题 | 说明 |
| --- | --- |
| 462 首不能播 | 见上「能力边界」，等 SAF 导入 |
| 通知卡片**内容**可能不完整 | 只验证了 `importance=DEFAULT` 与 MediaSession 存在，卡片排版未目视 |
| `main()` 疑似执行两次 | audio_service 起前台服务的副作用；日志里会有 1 条「通知权限通道不可用」WARN，**无功能影响** |
| 30 分钟后台播放 | 未做长时实测 |
| 多尺寸 / 四档字号 | 只在 Pixel 7（411dp）上验过 `normal` 与 `xlarge` 两档 |
| 深色「跟随系统」 | **未实现**（需要先定机制：5 套配色各配明暗 vs 只做一套暗色） |

## 五、怎么反馈

按优先级记，附上**机型 + 操作步骤 + 截图**：

- **P0**：崩溃 / 装不上 / 数据错乱（如 474 首查不到）
- **P1**：功能不可用（按钮点不动、播放失败、返回键行为异常）
- **P2**：样式/文案/间距不合适

日志位置：`adb shell run-as com.echohymn.app cat files/logs/app_*.log`（或 lite 版换包名）。
