# EchoHymn Android 安装指南（v1.9.2 · 主体 APK + 数据包）

## 一、安装包结构（`installer/output/android/`）

```
EchoHymn-v1.9.2.apk          主体程序（含数据库，无素材）  ≈56 MB
scores-0-237.zip             扫描图（简谱+五线谱 PNG）前半  ≈238 MB
scores-238-474.zip           扫描图 后半                    ≈250 MB
vocal-0-237.zip              人声（含 3/389 四部合唱、9 首鋼琴替代）前半 ≈230 MB
vocal-238-474.zip            人声 后半                      ≈685 MB
piano-0-237.zip              钢琴（含 249 人聲替代）前半    ≈545 MB
piano-238-474.zip            钢琴 后半                      ≈601 MB
SHA256SUMS.txt / BUILD-INFO.txt
```

每个包都 **< 2 GB**，按诗歌序号前半（1–237）/ 后半（238–474）拆分。

## 二、安装与导入步骤

1. 安装 `EchoHymn-v1.9.2.apk`（需允许「未知来源」）。
2. 打开应用 → 首启会显示「还没有导入诗歌数据」引导页。
3. 把需要的 zip 传到手机（Download 等任意位置），点「导入扫描图 / 导入人声 / 导入钢琴」，
   用系统文件选择器选中压缩包 → 等待进度完成。
4. **重启应用**：程序会按前十首检测实际素材，自动切换界面：
   - 钢琴 + 人声都有 → 全量版（可切换版本）
   - 只有钢琴 → 钢琴版（无版本按钮）
   - 只有人声 → 人声版（无版本按钮）
   - 都没有（只有扫描图）→ 读谱形态（无播放条）

> 导入规则：**只接受** `Hymn_Downloads/<目录>/<编号>_<类型>.<ext>` 且属于所选类别的文件；
> 同名文件直接覆盖；**规则外一律丢弃、不写入存储**（可放心选择整包）。

## 三、可选组合

| 需求 | 导入包 | 占用 |
|---|---|---|
| 只看谱/背词 | `scores-0-237` + `scores-238-474` | ≈488 MB |
| 只听钢琴 | `scores` ×2 + `piano` ×2 | ≈1.63 GB |
| 只听人声 | `scores` ×2 + `vocal` ×2 | ≈1.40 GB |
| 全量（钢琴+人声+谱） | 全部 6 个包 | ≈2.55 GB |

## 四、已知问题

| 问题 | 说明 |
| --- | --- |
| 导入后需重启 | 能力检测在启动时执行（后续版本可改为动态刷新） |
| 只导入前半包 | 前十首检测会判定为「有该素材」，但 238+ 首对应文件缺失（播放/看谱会失败）——建议整类导入 |
| 首启日志两条「HomeScreen 初始化」 | 双引擎并发（已知），DB 已做并发兜底，无功能影响 |
| 通知卡片内容 | 未目视；`importance=DEFAULT` 与 MediaSession 已验 |
| 30 分钟后台播放 | 未做长时实测 |

## 五、怎么反馈

按 **P0（崩溃/装不上/数据错乱）/ P1（功能不可用）/ P2（样式文案）** 记录，附机型 + 步骤 + 截图。
