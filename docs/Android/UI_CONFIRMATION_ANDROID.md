# EchoHymn Android UI 确认单（手机优先 · v1.0）

> **定位**：Android 移动端**像素级验收基准**（M2 前产出）；计划正文见 [ANDROID_PLAN.md](ANDROID_PLAN.md)（§3 为设计规则，本文为界面稿）。
> **基准机**：**412×915 dp**（竖屏）/ **915×412**（横屏）；**公差**：尺寸 ±2dp · 位置 ±2dp · 字号 ±0dp · 色值 ±2/255（方法见计划 §3.0.8）。
> **公共底座**：令牌 / 五态 / 动效 / 图标 / 无障碍标签 / 断点适配 → 计划 **§3.0**；导航与返回栈 → §3.9；深色谱面 → §3.10；缩放包络 → §3.11。

> **⚠️ 2026-11 变更摘要（与本文件设计稿冲突时以此为准）**
> 1. **「曲谱」模式仅 Windows**：Android 顶栏只有 歌词 / 简谱 / 五线谱（§3.14 曲谱分页仅桌面适用）；
> 2. **字号为 3 档**：标准 1.00 / 大 1.12 / 特大 1.26（第 4 档 `xlarge` 手机不显示）；
> 3. **Android 无音量控件**（图标 / 滑条 / 百分比均移除，用系统音量键）；横屏紧凑条同样不含音量；
> 4. **素材分发**：主体 APK（≈54 MB，含 DB）+ installer 数据包（扫描图/人声/钢琴 × 0-237/238-474），
>    首启引导或「设置 → 数据导入」导入；导入含逐文件 SHA-256 校验与「素材自检」；
> 5. **UI 形态由运行时检测决定**（首启前十首）：full / piano / vocal / lite，不再按 flavor 区分；
> 6. **lite 完全没有播放功能**（无播放条 / 媒体会话 / 通知权限）。
>
> 以下 13 个界面稿为 **2026-10 设计快照**，用于像素/栅格参考；上述 1~6 条已按新口径实现。

## 3.1.7 设置页（全屏 · **操作即见效果**）

| 项 | 定稿 |
| --- | --- |
| 入口 | 顶栏 `⋮` → 菜单（诗歌源考 / 设置 / 关于）；设置页为**独立全屏页**（非弹窗） |

| 横屏差异点 | 定稿 | 理由 |

### 3.14 曲谱按小节分页（**仅 Windows** 的核心显示方案）

> ⚠️ **2026-11 定稿**：Android / iOS **不提供「曲谱」模式**（顶栏无按钮；残留 `score` 状态回退歌词）。
> 本节仅适用于 Windows 桌面版；移动端相关任务（C-4/C-15）已调整为「三模式 + 扫描图」。

> **需求**：保留参照 APK 的曲谱显示技巧（**网格「列 = 拍点」· 同列对齐 · 记号自绘 · 小节线跨行**），但**不做"整首一屏"** —— 改为**按小节切分、一页一页翻**。

**分页规则**

| 项 | 定稿 |
| --- | --- |
| 切分边界 | **以 `barline` 单元格（小节线）所在列为页边界**；同一块（`K` 换表之前）内按小节顺序切 |
| 每页小节数 | **自适应（默认）**：可用宽 ÷ 单小节平均列宽，取 **2~4 小节**；可固定 2 / 3 / 4 |
| 页内渲染 | **完整复用 `JianpuGridView` 的渲染技巧**：槽宽 = 可用宽 ÷ 页内列数 → 同列同 x；八度点 / 减时线 / 延长记号自绘；小节线按 `rowspan` 画满 |
| 歌词行 | 按**当前页的列范围切片**，仍与音符同列对齐（不丢对齐信息） |
| 跨行小节线 | 页边界处 `rowspan` 只画到本页末行；下一页首列重画（视觉连续） |
| 块边界 | 每块独立分页；总页数 = 各块页数之和 |
| 页脚 | 「◀ 第 2 / 7 页（第 5~8 小节） ▶」+「手动 / 自动」 |
| 自动翻页 | `autoPageIndexFor(position, totalSeconds, pageCount)`（与歌词页同一函数）；无音频版用虚拟进度（§3.1.15）驱动 |
| 与歌词页关系 | **歌词模式仍按「节」分页**，曲谱按**小节**分页，两者独立互不影响 |
| 设置项 | 「曲谱 → 每页小节数：**自适应（默认）** / 2 / 3 / 4」 |

**实现方式**

| 方案 | 做法 | 取舍 |
