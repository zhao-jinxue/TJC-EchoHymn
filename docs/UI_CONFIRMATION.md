## 3. 弹窗（已确认）

### 3.1 个人歌单创建弹窗（480×320）

- 顶部标题「个人歌单创建」
- 歌单名称输入框（**最多 30 字**）
- 搜索框（输入编号/名称，点击搜索按钮或回车 → 弹出「诗歌弹窗」）

- 底部：「取消」「创建」按钮（创建 → 写入数据库 → 回到个人歌单列表）

### 3.2 诗歌弹窗

- 顶部标题「诗歌展示」
- 编号 + 诗歌名称
- 歌词区域（展示简谱歌词）
- 底部：「取消」「添加」按钮（添加 → 该诗加入当前创建的歌单并出现在已添加列表）
