# 🎵 EchoHymn · 赞美诗与颂歌

一个简洁优雅的经典赞美诗聆听网站，支持诗歌列表浏览、歌词展示与音频播放。

## ✨ 功能

- 📜 **诗歌列表**：左侧边栏展示诗歌编号与标题，支持搜索（编号 / 标题 / 作者 / 分类）
- 🎼 **歌词显示**：选择诗歌后，分节展示歌词
- ▶️ **音频播放**：播放 / 暂停、上一首 / 下一首、进度拖动、音量调节
- ⌨️ **键盘快捷键**：`空格` 播放/暂停，`←` 上一首，`→` 下一首
- 📱 **响应式布局**：移动端自动收起侧边栏

## 📁 项目结构

```
EchoHymn/

├── css/

├── js/
│   └── app.js        # 播放器与交互逻辑
├── data/
│   └── hymns.js      # 诗歌数据（标题、作者、歌词、音频 URL）

```

## 🚀 运行方式

直接使用浏览器打开 `index.html` 即可，无需构建或安装依赖。

> 建议通过本地静态服务器预览（部分浏览器限制本地文件的音频跨域加载）：
>
> ```bash
> python -m http.server 8000
> # 然后访问 http://localhost:8000
> ```

## 🎶 添加诗歌

编辑 `data/hymns.js`，按以下格式添加条目：

```js
{
    id: 9,
    number: 9,
    title: "诗歌标题",
    author: "作词者",
    composer: "作曲者",
    category: "分类",
    audio: "https://example.com/audio.mp3",
    lyrics: [
        ["第一行歌词", "第二行歌词"],
        ["第二段第一行", "第二段第二行"]
    ]
}
```

## ⚠️ 说明

- 演示音频使用 Pixabay 的公有领域古典乐资源，因版权原因并未提供真实赞美诗歌声，仅用于演示播放功能。
- 如需正式使用，请替换为自有或正版授权的音频文件（也可将音频放入 `audio/` 目录后使用相对路径）。
