# EchoHymn 赞美诗播放软件 V1.5 用户操作手册

## 1 引言

### 1.1 编写目的

本手册面向 EchoHymn 赞美诗播放软件（以下简称"本软件"）的使用者，说明本软件的运行环境、安装方法与各项功能的详细操作步骤，并给出常见异常的处理指引。手册内容与本软件 V1.5 版本的功能实现一致。

### 1.2 软件概述

本软件是一款本地运行的赞美诗歌播放与浏览应用，界面品牌名为 EchoHymn。软件收录《赞美诗歌》（增订本）共 474 首诗歌、45 条二级分类，全部数据与音视频素材存储于本机，无需联网即可使用。主要功能包括：

- 按编号分页浏览诗歌库，按分类目录浏览默认歌单，创建并管理个人歌单；
- 按编号即时定位诗歌，按歌名与歌词进行模糊搜索；
- 离线播放钢琴版与人声版音频，支持版本切换与多个人声版本选择；
- 以歌词、简谱、五线谱三种模式显示当前诗歌，谱面图片支持缩放与滚动查看；
- 显示诗歌源考资料（创作背景、词曲作者信息）；
- 五套界面配色与四级字号调节，全部个性化设置与播放状态自动记忆；
- 内置用户手册，支持全局键盘快捷键与通用媒体键操作。

本软件目标平台为 Windows 桌面（64 位），采用单实例运行保护，重复启动时自动聚焦已运行的窗口。

### 1.3 术语约定

## 2 运行环境

### 2.1 硬件环境

| 项目 | 要求 |
| --- | --- |

## 3 软件安装与初始化

### 3.1 分发文件

本软件以两个文件为一组分发，安装前须将二者放入同一文件夹：

- `EchoHymn_Setup_v<版本>.exe` —— 安装向导（约 33 MB，内嵌主程序载荷）；
- `EchoHymn_Data_v<版本>.7z` —— 外置加密诗歌素材包（约 3 GB）。

两组文件均附带 `.sha256` 校验值，可用于核对文件完整性。

[此处插入：安装文件就位（双文件同目录）截图]

### 3.2 安装步骤

1. 双击 `EchoHymn_Setup_v<版本>.exe`，在用户账户控制弹窗中点击"是"。若系统弹出 SmartScreen 提示"Windows 已保护你的电脑"，点击"更多信息"后再点击"仍要运行"即可（安装包未做商业代码签名，该提示属正常现象）。
2. **第一步·系统兼容性检查**：安装向导自动检测 64 位系统、Windows 10 以上版本、媒体功能、素材文件是否同目录就位、磁盘剩余空间等项目，全部显示"✔"后方可继续；素材文件缺失时对应项显示"✘"并阻断安装，补齐文件后点击"重新检测"按钮复查。
3. **第二步·选择安装位置**：默认为 `D:\Program Files\EchoHymn`；无 D 盘或剩余空间不足时自动回退至 `C:\Program Files\EchoHymn`，用户也可手动更改。
4. **第三步·誓言宣誓**：页面展示一段宣誓词，用户须逐字键入（该页为个人使用承诺环节，展示框不可复制粘贴）。输入与誓词一致（忽略空白、半角标点自动归一）即校验通过并开始安装；不一致时红字提示并停留在本页。
5. 安装分两段解包：先释放程序文件（秒级完成），再解密释放诗歌素材（约 3 GB，视磁盘速度需数分钟，页面显示百分比进度）。
6. 安装尾步，程序自动为安装目录授予普通用户修改权限（保障状态文件与日志可写），并创建开始菜单与桌面快捷方式；勾选"立即运行"可在完成后直接启动。

[此处插入：安装向导弹（环境检查页）截图]

### 3.3 升级安装与卸载

- **升级安装**：运行新版安装包，环境检查通过后选择原安装目录即可覆盖更新；个人歌单数据、状态文件与日志自动保留。
- **卸载**：通过开始菜单"EchoHymn · 聆听赞美诗 → 卸载 EchoHymn"或控制面板"程序和功能"执行。卸载时会询问是否保留个人数据（个人歌单、状态文件、日志），默认建议保留。

### 3.4 首次启动与初始化

1. 双击桌面快捷方式或安装目录中的 `echo_hymn.exe` 启动本软件。
2. 首次启动自动弹出内置用户手册，展示软件介绍、操作说明与快捷键表；关闭手册即进入主界面。
3. 软件自动加载本机诗歌数据库并恢复上次退出时的浏览与播放状态；恢复状态下进度条从 0 开始，不自动播放音频。
4. 手册弹窗底部的"启动时显示本手册"勾选框可控制此后每次启动是否自动弹出该手册。

## 4 核心功能操作说明

### 4.1 主界面与窗口操作

本软件界面自上而下分为：自绘标题栏、顶栏、内容区（左侧栏 / 主内容区 / 右侧栏）、底部状态栏；左右侧栏可通过顶栏两端箭头展开或收起。

1. 按住标题栏空白处拖动可移动窗口；双击标题栏空白处在最大化与还原之间切换。
2. 标题栏右侧按钮组从左至右依次为：调色盘（配色）、"大小写T"（字号）、"?"（用户手册）、最小化、最大化/还原、关闭。
3. 改变窗口大小时，界面内容整体等比缩放，不发生变形或裁切。
4. 本软件限制单实例运行：已启动时再次双击快捷方式，系统聚焦既有窗口而不重复开启新进程。

[此处插入：主界面整体布局（含左右侧栏展开）截图]

### 4.2 诗歌库浏览

左侧栏提供三个栏目，点击栏目名称切换：

1. **诗歌列表**：按编号顺序分页展示全部 474 首诗歌，每页 35 首，点击底部页码可前后翻页；点击任一诗歌即在主内容区载入并播放。
2. **默认歌单**：按"一级分类 → 二级分类"两级目录展开浏览，点击分类下的诗歌即播放。
3. **个人歌单**：展示用户自建歌单列表，点击歌单名称即展示其诗歌列表，并可整单播放。
4. 正在播放的诗歌在列表中高亮显示；通过任何方式切歌时，所在列表自动滚动跟随高亮项。

### 4.3 个人歌单管理

1. **新建歌单**：在"个人歌单"栏目点击新建按钮，输入歌单名称并确认；名称重复时软件提示并要求改名。
2. **改名与删除**：选中已有歌单，通过修改入口可更改歌单名称，或删除该歌单；删除前软件弹出确认提示。
3. **加入诗歌**：浏览诗歌列表时将当前诗歌加入指定歌单；同一歌单不可重复加入同一首诗歌。
4. 歌单数据保存于本机数据库文件中，升级安装与保留数据的卸载不会造成丢失。

### 4.4 搜索与定位

搜索框位于"诗歌列表"栏目内，支持两种输入方式：

1. **按编号定位**：输入纯数字后按回车，软件自动翻页定位并高亮该编号诗歌（不自动播放）；焦点仍在搜索框时再次按回车开始播放，播放后搜索框自动清空。
2. **按歌名/歌词模糊搜索**：输入中文关键词按回车，软件同时对歌名与歌词进行模糊匹配（支持繁简体双向匹配）；命中时弹出统一结果列表，按"编号 / 诗歌名称 / 歌词"三列展示。
3. 结果列中，歌名命中的关键词以红色加粗显示，歌词命中的关键词以蓝色加粗显示并从命中行开窗展示该节歌词（行首以"…"表示截断）；同一首歌两种命中并存时同屏显示。
4. 在结果列表中单击某行选中该行，双击该行则关闭弹窗、在左栏定位该诗歌并开始播放。
5. 无命中时不弹窗，列表区显示"未找到匹配的诗歌"提示；点击搜索框内的清除按钮（×）回到当前播放定位行。

### 4.5 歌词与谱面显示

主内容区顶部提供"歌词 / 简谱 / 五线谱"三个显示模式按钮：

1. **歌词模式**：整屏显示当前诗歌歌词，字号随窗口大小自动铺满；歌词超出一屏时可滚动阅读。
2. **简谱 / 五线谱模式**：显示该诗歌的曲谱图片。图片默认以适配宽度显示；鼠标指针位于谱面区域内时，按住 Ctrl 滚动滚轮放大或缩小图片，宽度最大可放大至铺满歌词显示区，高度按比例同步；直接滚动滚轮则上下翻看图片内容；图片超出显示区时右侧出现纵向滚动条。
3. 切换诗歌后，谱面图片的缩放与滚动位置自动复位为初始视图。

### 4.6 音频播放

1. **版本切换**：主内容区版本栏提供"钢琴版 / 人声版"两个按钮，点击切换当前诗歌的播放版本；所选版本选择自动记忆，重启后保持。某首诗歌缺少所选版本时，软件临时改用另一版本播放，记忆的设置不变。
2. **多版本选择**：当前诗歌存在多于一个人声版本时，播放条右侧出现"👥"按钮，点击可选择具体版本。
3. **播放控制**：播放条提供上一首、播放/暂停、下一首三个控制键，按播放列表顺序循环切换；进度条可拖动跳转，两端显示当前播放位置与总时长。
4. **音量**：播放条左侧音量控件支持点击图标静音/恢复、拖动滑条调节；滑条与 Windows 系统音量双向同步（滑条即系统音量镜像），右侧数字显示当前音量百分比。
5. 音频播放出错时，软件在界面底部以气泡提示具体原因，并记录到本机日志文件。

### 4.9 内置用户手册

1. 打开方式（三种）：点击标题栏"?"按钮；在软件任意界面按 F1 键；启动软件时按设置自动弹出。
2. 关闭方式（三种）：按 Esc 键；点击弹窗右上角"✕"；点击弹窗外任意位置。
3. 手册内容分三部分：软件介绍、操作说明、快捷键说明；重复触发打开不会叠加多个弹窗。
4. 弹窗底部"启动时显示本手册"勾选框控制每次启动是否自动弹出，设置自动记忆。

### 4.10 快捷键与滚轮操作

本软件支持全局键盘快捷键，任意界面（含弹窗打开时）均可使用：

| 功能 | 快捷键 / 滚轮 |
| --- | --- |
| 播放 / 暂停 | 空格键 或 Ctrl+P |
| 下一首 | Ctrl+→ 或 Alt+→ |
| 上一首 | Ctrl+← 或 Alt+← |
| 音量增大 | Ctrl+↑ |
| 音量减小 | Ctrl+↓ |
| 静音 / 取消静音 | Ctrl+M |
| 打开用户手册 | F1 |
| 关闭用户手册 | Esc |
| 谱面图片放大 / 缩小 | Ctrl+滚轮 |
| 谱面图片上下滚动 | 滚轮 |
| 浏览列表 / 歌词 / 诗歌源考 | 滚轮 |

补充说明：

1. 键盘输入框获得焦点时，空格键仍用于输入文字，不触发播放/暂停。
2. 通用媒体键（播放/暂停、上一首、下一首、音量）可直接控制本软件。
3. 滚轮操作仅在鼠标指针位于对应区域（谱面图片、诗歌列表、歌词、源考栏）时生效。

### 4.11 状态记忆与本机数据

1. 本软件自动记忆上次退出时的使用状态，包括：左侧栏栏目与页码、所选歌单与当前诗歌、音频版本、显示模式（歌词/简谱/五线谱）、侧栏展开状态、配色、字号与手册弹出偏好。
2. 状态数据保存在程序主程序文件同级的 `state.json` 文件中，采用原子写入方式，随安装目录整体拷贝即可迁移。
3. 启动恢复状态时不自动播放音频，播放进度从 0 开始；恢复完成后，如滚动位置等校验存在异常，将在底部状态栏报告。
4. 本软件在程序同级 `logs\` 目录按天生成文本运行日志，自动保留最近 7 份，程序内部错误与音频异常均被记录，可供排查问题时查阅。

## 5 异常处理与常见问题

**问题 1：安装时环境检查出现"✘"项。**
处理：素材文件缺失时，将 `EchoHymn_Data_v<版本>.7z` 与安装包放入同一目录后点击"重新检测"；磁盘空间不足时清理目标分区至要求值后重新检测；Windows N/KN 版系统提示媒体功能缺失时，先安装系统"媒体功能包"。

**问题 2：双击安装包时 Windows 提示"已保护你的电脑"。**
处理：这是未签名安装程序的正常 SmartScreen 提示，点击"更多信息"→"仍要运行"即可继续。

**问题 3：软件启动后播放无声音。**
处理：检查系统音量是否被静音（本软件音量滑条与系统音量一致）；确认音频输出设备正常；确认系统具备 Media Foundation 功能（见问题 1）。

**问题 4：按空格键不触发播放/暂停。**
处理：当光标位于文字输入框（如搜索框）内时，空格用于输入文字；点击界面空白处使输入框失去焦点后再按空格。

**问题 5：升级安装后打开软件仍是旧界面。**
处理：升级前请完全退出正在运行的旧版本（本软件为单实例，旧进程未退出时启动的仍是旧进程）；从任务栏或系统托盘确认退出后重新启动。

**问题 6：某首诗歌点击后提示音频文件不存在。**
处理：诗歌素材目录 `Hymn_Downloads` 内容不完整或被移动过；请通过完整安装包重新安装，或核对素材目录是否保持安装时的原始结构。

**问题 7：卸载后重新安装，个人歌单不见了。**
处理：卸载时如选择"不保留个人数据"，个人歌单与状态文件将被一并删除且不可恢复；建议卸载时选择保留。

**问题 8：底部状态栏显示恢复校验提示。**
处理：该提示表明上次退出时的列表滚动位置在本次启动时无法精确还原，不影响任何功能；点击目标诗歌即可正常定位与播放。
