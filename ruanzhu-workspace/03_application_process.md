
# 计算机软件著作权申请全流程文档 (个人名义)

当您使用 Cline 成功输出了 `source_code.txt` 和 `user_manual_draft.md` 后，请按照以下流程向中国版权保护中心提交申请。

## 阶段一：材料终审与转换 (线下准备)

AI 生成的材料不能直接上传，需经过人工排版转换：

### 1. 源代码文档化

- 打开 Word，将 `source_code.txt` 的内容粘贴进去。
- **页面设置**：A4纸，纵向。
- **页眉**：左侧填写“软件全称+版本号”（如：XX管理系统 V1.0），右侧留空或填页码。
- **字体字号**：建议使用小五号或五号字体（如 Consolas 或 Courier New 等等宽字体），确保**每页正好是 50 行**（第60页除外）。
- **页码**：底部居中，1-60连续编号。
- 导出为 PDF 文件：`源代码.pdf`。

### 2. 用户手册完善

- 将 `user_manual_draft.md` 转换为 Word 文档。
- **填补截图**：根据文中的 `[此处插入：XXX界面截图]` 占位符，截取您软件真实的运行界面插入其中。
  - *注意：截图必须清晰，截图上的软件名称必须与申请的软件全称一致！如果不一致，宁可P图改名字也不能出现矛盾。*
- **排版**：添加封面（包含软件名称、版本号、申请人姓名）、目录。正文建议15页以上。
- 导出为 PDF 文件：`用户手册.pdf`。

### 3. 身份证明

- 准备好个人身份证正反面扫描件（彩色，清晰，合并为一个PDF或JPG）。

## 阶段二：账号注册与实名认证 (线上)

1. 访问 **中国版权保护中心官网**：[https://www.ccopyright.com.cn](https://www.ccopyright.com.cn)
2. 点击右上角“注册”，选择“个人”身份。
3. 填写真实姓名、身份证号、手机号等信息。
4. **实名认证**：根据系统提示完成人脸识别或银行卡认证（目前政策要求必须先实名才能填报）。认证通常需要 1-3 个工作日审核，请提前办理。

## 阶段三：在线填报申请表

实名认证通过后，登录系统，进入“版权登记” -> “计算机软件著作权登记” -> “立即办理”。

逐项填写表单（以下为易错项提醒）：

- **软件全称**：必须以“软件”、“系统”、“平台”、“插件”、“APP”等结尾。不能只有品牌名（如不能叫“微信”，必须叫“微信通讯软件”）。
- **版本号**：通常为 V1.0 或 1.0。
- **开发完成日期**：必须早于或等于“首次发表日期”。如果是未发表的软件，勾选“未发表”。
- **权利取得方式**：选择“原始取得”。
- **软件用途和技术特点**：简明扼要描述，字数不宜太少，可从 AI 生成的手册引言中提取。
- **硬件/软件环境**：如实填写（如：服务器端 Linux，客户端 Windows 10/Android 12等）。
- **编程语言及代码量**：如实填写（如：Python, JavaScript；3500行）。
- **上传附件**：按要求上传前面准备好的 `源代码.pdf`、`用户手册.pdf` 和 `身份证扫描件`。

## 阶段四：提交与审查

1. **确认提交**：检查无误后点击提交。系统会生成流水号。
2. **受理通知**：版权中心会对材料进行形式审查。如果符合基本要求，会下发《受理通知书》（电子版）；如果不符合，会下发《补正通知书》。
   - *收到补正通知不要慌，按照通知上的要求（如：某页代码有乱码、某处名称不一致）修改后重新上传即可。*
3. **审查周期**：
   - 普通件：受理后约 30-60 个工作日（目前官方免费，但排队较长）。
   - 如需加急：官方通道无加急，需通过具有资质的代理机构走加急通道（需付费，通常 3-30 个工作日出证）。
4. **获取证书**：审查通过后，系统发放电子版《计算机软件著作权登记证书》。您可以自行下载打印，电子证书与纸质证书具有同等法律效力。

## 阶段五：后续维护建议

- **妥善保管底稿**：将 Cline 整理的原始代码版本和最终提交版妥善保存在本地或私有Git仓库，以备未来发生侵权纠纷时作为“开发过程证据”。
- **版本迭代**：如果软件发生重大升级（如 V1.0 升级到 V2.0，且代码变动超过30%），建议重新申请一次新版本的软著。
