## 软件全称 / 简称 / 版本号

- 全称：**EchoHymn 赞美诗播放软件**（证书及全部材料页眉统一此名）
- 版本号：**V1.5**

## 开发目的（约 60 字）

为教堂礼拜与个人离线聆听赞美诗的场景，提供一款本地运行的诗歌播放与浏览桌面软件，实现诗歌检索、歌词与曲谱显示、音频播放及播放状态记忆等功能。

## 软件用途（约 100 字）

本软件用于基督教赞美诗的播放与浏览。收录《赞美诗歌》（增订本）474 首诗歌、45 条分类，全部数据与音频、曲谱素材存储于本机，无需联网运行；支持分类歌单与个人歌单管理、编号与歌名歌词模糊搜索、歌词/简谱/五线谱三种显示模式、钢琴版与人声版音频播放，主要面向礼拜仪式及信众日常灵修聆听场景。

## 技术特点 · 精简版（申报表用）

> 计数：99 字（含标点与英文，实测 len()，满足"100 字以内"）。

基于Flutter/Dart构建桌面应用，自绘标题栏与单实例控制；SQLite存储诗歌数据，纯Dart实现简繁转换与歌名歌词模糊搜索；直读中文路径本地音频，状态原子持久化，界面等比缩放，全离线运行。

## 技术特点 · 详版（约 420 字，栏位允许时用，或供"其他说明"页）

1. 采用 Flutter 框架以 Dart 语言实现界面与业务逻辑，配合 Win32 C++ 原生窗口层：移除系统标题栏自绘窗口标题栏，通过自定义 MethodChannel 实现窗口尺寸控制、拖拽、最大化感知与 CreateMutex 单实例保护。
2. 数据层为嵌入式 SQLite 数据库（474 首诗歌、45 条分类、个人歌单单表 JSON 结构），配合界面状态文件 `state.json` 的原子写入与全进程唯一串行写队列，杜绝并发损坏；启动自动恢复上次会话状态并进行滚动位置校验（误差 ≤2 像素）。
3. 纯 Dart 实现的简繁字符映射转换与歌名、歌词双路模糊搜索（繁简双向匹配、关键字加粗、命中节开窗显示），无原生依赖、无网络依赖。
4. 音频经 audioplayers（Windows Media Foundation）以设备文件源直读含中文路径的本地文件；音量控制与 Windows 系统音量双向镜像同步，并通过根 Focus 事件冒泡实现全局快捷键与通用媒体键控制。
5. 界面渲染层以 Transform.scale 实现窗口大小改变时整树等比缩放；谱面图片采用宽度驱动缩放（LayoutBuilder 实时取界、Ctrl+滚轮缩放与滚轮滚动经 PointerSignalResolver 分流），换曲自动复位。
6. 内置子集化字体（Noto Sans SC 子集，OFL 许可）保证跨机器渲染一致；按天轮转的文本日志（保留 7 份）与全局异常捕获用于故障回溯；分发采用 Inno Setup 三页向导与 AES-256 加密双载荷（主程序约 33MB、素材约 3GB）安装。
