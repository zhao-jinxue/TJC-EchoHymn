# EchoHymn v1.5.1 搜索修复复测清单（R01~R20）

> **对应首轮**：`v151_search_test_cases.md`（S01~S41）中 6 条 NG（S02/S04/S09/S11/S24/S27）的修复复测 + 用户手册子项化验收（任务：操作说明拆子项）  
> **修复摘要**：① 编号二次回车播放后**自动清空搜索框**（S02）；② ×/删空清框后**强制滚回定位行**——行高近似误判与列表重建时序双修（S04）；③ 弹窗关闭回焦搜索框时**取消全选、光标折叠到末尾**（S09）；④ 中文回车**永远只弹窗、绝不直接播放**——弹窗双击是唯一播放入口，再次回车 = 重新弹窗（S11/S24 交互重定义）；⑤ 歌词命中单元格**从关键字所在行开窗显示**（带 `…` 前缀），保证加粗关键字始终可见（S27 根因：单元格只显 3 行，关键字在节末行被截断）；⑥ 用户手册操作说明重构为「小节标题 + 子项」两级结构。  
> **测试平台**：Windows（`echo_hymn.exe` release 版）
