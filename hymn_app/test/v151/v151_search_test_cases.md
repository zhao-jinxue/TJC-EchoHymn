# EchoHymn 歌名+歌词统一搜索测试清单（S01~S41）

> **功能**：中文关键字同时模糊搜索歌名+歌词，命中统一进三列弹窗表格（编号 / 诗歌名称 / 歌词）；歌名关键字红色加粗、歌词关键字主题色加粗（显示第一个命中节）；单击选中、双击跳转定位并播放；编号搜索保持不变  
> **测试平台**：Windows（`echo_hymn.exe`）  
> **测试方法**：人工/手工测试  
> **测试准备**：① 从 `release/` 最新版运行；② 每项如实填写「实际结果（OK/NG）」，NG 记录具体现象。
