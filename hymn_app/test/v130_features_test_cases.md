# EchoHymn v1.3.0 新增功能测试用例清单

> **版本**：v1.3.0（`9a9452c`，自定义标题栏 + 全局播放快捷键 + 用户手册）  
> **测试平台**：Windows（`echo_hymn.exe`）  
> **测试方法**：人工/手工测试  
> **测试准备**：① 从 `release/` 最新版或 `hymn_app/build/windows/x64/runner/Release/` 运行；② 选择一首含音频的诗歌；③ 若键盘带媒体键（播放/上一首/下一首/音量），准备测试 S11；④ 每项如实填写「实际结果（OK/NG）」，NG 记录具体现象。

## 二、全局播放快捷键（通用方案）

| 编号 | 测试场景 | 测试动作 | 预期结果 | 实际结果（OK/NG） | NG 状态 |
| --- | --- | --- | --- | --- | --- |
| S01 | 空格 = 播放/暂停 | 选中一首歌后按 `空格` | 播放 / 暂停切换；播放条按钮与状态栏进度同步 | | |
| S02 | Ctrl+P = 播放/暂停 | 播放中按 `Ctrl+P` | 暂停；再次按 `Ctrl+P` 恢复播放 | | |
| S03 | Ctrl+→ 下一首 | 播放中按 `Ctrl+→` | 切到下一首；左栏高亮联动滚动 | | |
| S04 | Ctrl+← 上一首 | 播放中按 `Ctrl+←` | 切到上一首 | | |
| S05 | Alt+→ 下一首 | 按 `Alt+→` | 切到下一首 | | |
| S06 | Alt+← 上一首 | 按 `Alt+←` | 切到上一首 | | |
| S07 | Ctrl+↑ 音量增大 | 反复按 / 长按 `Ctrl+↑` | 音量逐步增大；**长按连续增大** | | |
| S08 | Ctrl+↓ 音量减小 | 反复按 / 长按 `Ctrl+↓` | 音量逐步减小；**长按连续减小**；到 0 不再变小 | | |
| S09 | Ctrl+M 静音 | 播放中按 `Ctrl+M` | 立即静音；再次按 `Ctrl+M` 恢复原音量 | | |
| S10 | F1 打开手册 | 按 `F1` | 弹出「用户手册」弹窗 | | |
| S11 | 键盘媒体键 | （有媒体键键盘时）按 播放/暂停、上一首、下一首、音量± | 对应动作生效（同 S01/S03/S04/S07/S08） | | |
| S12 | 输入框聚焦时空格 | 焦点在搜索框 / 歌单名称输入框 → 输入空格 | **空格作为文字输入**，不触发播放/暂停 | | |
| S13 | 输入框聚焦时 Ctrl 快捷键 | 焦点在搜索框 → 按 `Ctrl+P` | 仍可播放/暂停，不影响输入内容 | | |
| S14 | 长按空格防抖 | 按住 `空格` 不放 2 秒 | 只触发**一次**播放/暂停，不连发 | | |
| S15 | 弹窗内快捷键 | 打开「用户手册」弹窗 → 按 `空格` / `Ctrl+P` | 仍可控制播放/暂停；弹窗保持打开 | | |
| S16 | 未选歌曲时快捷键 | 首次启动未选择歌曲 → 按 `空格` / `Ctrl+P` | 无崩溃；按当前播放列表从合理位置开始播放（按实际行为记录） | | |
| S17 | 快捷键与输入不冲突 | 个人歌单创建弹窗内输入名称 → 正常打字 + `Ctrl+M` | 文字输入正常；Ctrl+M 仍可静音 | | |
