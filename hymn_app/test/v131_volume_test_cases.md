# EchoHymn v1.3.1 音量调节功能测试用例清单

> **版本**：v1.3.1（播放条音量控件 + 快捷键联动）  
> **测试平台**：Windows（`echo_hymn.exe`）  
> **测试方法**：人工/手工测试  
> **测试准备**：① 从 `release/` 最新版或 `hymn_app/build/windows/x64/runner/Release/` 运行；② 播放一首含音频的诗歌；③ 每项如实填写「实际结果（OK/NG）」，NG 记录具体现象。

---

## 一、音量控件 UI（播放条左侧）

| 编号 | 测试场景 | 测试动作 | 预期结果 | 实际结果（OK/NG） | NG 状态 |
| --- | --- | --- | --- | --- | --- |
| V01 | 音量控件位置 | 查看播放条 | 播放按钮组（上一首/播放/下一首）**左侧**出现音量控件：**音量图标 + 滑条 + 音量百分比** | | |
| V02 | 默认音量 | 首次启动 | 滑条在 100% 位置，百分比显示「100%」，图标为音量符号（volume_up） | | |
| V03 | 拖动滑条调节 | 拖动音量滑条（如拖到中部） | 音量实时变化（可听出），百分比文字同步更新（如 50%） | | |
| V04 | 滑条拖到最小 | 将滑条拖到最左（0） | 播放无声；百分比显示「0%」；图标仍为音量符号（音量 0 ≠ 静音状态） | | |
| V05 | 点击图标静音 | 播放中点击音量图标 | 图标变为静音符号（volume_off）；百分比显示「0%」；滑条归零；**立即无声** | | |
| V06 | 再次点击取消静音 | 静音状态下再点图标 | 图标恢复音量符号；百分比恢复**静音前音量**；滑条回到原位置；恢复播放 | | |
| V07 | 图标 Tooltip | 悬停音量图标 | 显示 Tooltip：静音（Ctrl+M）/ 取消静音（Ctrl+M） | | |

## 二、快捷键与 UI 联动（同一系统）

| 编号 | 测试场景 | 测试动作 | 预期结果 | 实际结果（OK/NG） | NG 状态 |
| --- | --- | --- | --- | --- | --- |
| V08 | Ctrl+↑ 同步 UI | 播放中按 `Ctrl+↑` | 音量增大（听得出）；**滑条位置 / 百分比文字实时同步增大** | | |
| V09 | Ctrl+↓ 同步 UI | 播放中按 `Ctrl+↓` | 音量减小；**滑条位置 / 百分比文字实时同步减小** | | |
| V10 | Ctrl+M 同步 UI | 播放中按 `Ctrl+M` | 图标变静音符号、百分比变 0%、滑条归零；再按 `Ctrl+M` 全部恢复（图标/百分比/滑条） | | |
| V11 | 静音时 Ctrl+↑ 取消静音 | 静音后按 `Ctrl+↑` | **自动取消静音**：图标恢复音量符号、百分比从 0 增大、滑条移动；声音恢复 | | |
| V12 | UI 与快捷键接力调节 | 拖动滑条到 30% → 再按 `Ctrl+↑` 数次 → 再拖动滑条 | 数值始终**基于上一次的值**连续变化，无跳变、无回退（同一数据源） | | |
| V13 | 长按 Ctrl+↑ 连续增大 | 长按 `Ctrl+↑` 2 秒 | 音量连续增大，滑条/百分比持续刷新；到 100% 封顶不再增大 | | |
| V14 | 长按 Ctrl+↓ 连续减小 | 长按 `Ctrl+↓` 2 秒 | 音量连续减小，滑条/百分比持续刷新；到 0% 封底 | | |
