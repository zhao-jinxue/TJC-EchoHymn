# EchoHymn v1.4.0 换肤功能测试用例清单

> **版本**：v1.4.0（五套配色 + 标题栏换肤按钮 + 配色持久化）  
> **测试平台**：Windows（`echo_hymn.exe`）  
> **测试方法**：人工/手工测试  
> **测试准备**：① 从 `release/` 最新版或 `hymn_app/build/windows/x64/runner/Release/` 运行；② 展开左右侧栏便于观察整体配色；③ 每项如实填写「实际结果（OK/NG）」，NG 记录具体现象。
