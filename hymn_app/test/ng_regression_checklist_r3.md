# EchoHymn 回归测试用例清单（第三轮 · 2026-08-28）

> **填写说明**：按「测试动作」逐步操作，核对「预期结果」是否达成；实际结果填「OK」或「NG」，NG 记录具体现象。

## 一、窗口与布局

| 编号 | 测试场景 | 测试动作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- | --- |
| K10b | 重启后侧栏展开状态的最小尺寸 | 展开左栏/右栏 → 关闭程序 → 重新打开 → 直接拖动窗口缩小 | 窗口停在被允许的最小尺寸 = 基座 850×890 + 已展开栏宽（左栏≥1200 / 左右栏≥1800 客户区），**不能缩到 850×890** | |
| K10b2 | 收起状态的最小尺寸 | 两侧栏均收起 → 拖动窗口缩小 | 窗口停在基座 850×890，不能更小 | |
| K10b3 | 展开→收起→展开循环 | 反复展开/收起左栏多次，每次展开后拖动缩小 | 每次展开后最小尺寸都正确含侧栏（不残留旧值、不被覆盖） | |
| K10c | 窗口放大后歌词自适应 | 播放一首歌 → 把窗口拉大（横向/纵向） | 歌词字号随窗口变大继续增大并**铺满歌词区**（不因字号封顶出现大片空白） | |
