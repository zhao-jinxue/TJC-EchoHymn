# EchoHymn v1.5.0 字号切换功能测试用例清单

> **版本**：v1.5.0（四级字号 + 全局等比缩放 + 字号持久化）  
> **测试平台**：Windows（`echo_hymn.exe`）  
> **测试方法**：人工/手工测试  
> **测试准备**：① 从 `release/` 最新版或 `hymn_app/build/windows/x64/runner/Release/` 运行；② 每项如实填写「实际结果（OK/NG）」，NG 记录具体现象；③ 字号系数：默认 ×1.0 / 中号 ×1.3 / 大号 ×1.6 / 最大 ×1.9。
